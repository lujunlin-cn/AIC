# R13 复盘：为什么对手到 45 而我们停在 35（2026-10-08）

触发：QV 双 seed 平台 35.08/34.94（判负关闭）；用户情报对手已冲 45。

## 1. 45 分的算术分解（假说，但算术精确得可疑）

| 锚点 | 分数 | 来源 |
|---|---:|---|
| 复赛 B0（YuNet+全选） | **31.58** | 实测（20261002_real_score_anchor） |
| 初赛 B0（YuNet+全选，174 集） | 34.42 | 实测（20260928_score_46_84_followup） |
| 初赛 NOFACE（32B 教师主体点） | 42.83 | 实测，**+8.41 纯教师空间点位** |
| 初赛 TEMP（+教师语义删片尾/黑屏） | 46.84 | 实测，**+4.01 纯教师时间语义清理** |
| 初赛 DT_V3/INTERP 终态 | 47.88/48.67 | 实测 |

**假说**：对手 45 ≈ 31.58 + (47.88 − 34.42) = **45.04**。
即「把初赛验证过的教师语义管线（语义主体点位 + 语义时间清理）以 ≤9B 合规形态
在复赛集重演」。这不是唯一解释，但它是唯一一个由我方两套实测数据（初赛增益分解
×复赛 B0）直接支撑的解释。

## 2. 我们 12 轮为什么原地踏步（证据链）

1. **复赛时间轴我们只部署过「帧级排序头」**：TCN（+0.13）→ GATT/PHD2（+0.42）
   → QV saliency（−0.09）。全部是「在 31.58 的全选地面上薄薄刮一层」。
2. **历史上唯一的大时间增益来自语义级视频理解**：TEMP 删片尾/黑屏/推广卡 +4.01
   （32B 教师判断「这是抖音推广片尾」，不是给帧打分）。复赛**从未部署过**。
3. **教师机制被误判为「复赛失效」**：教师包复赛 34.84，我们据此放弃了教师路线。
   但 (a) 教师 62GB 在 >9GB 档被 k_size 压制（当时 VISIONONLY 实验已实证 k 不兑现，
   却没有反推到教师包）；(b) 初赛 47.88 → 复赛 34.84 的 -13 分里还叠加了短视频域差
   （复赛 p50=14.1s vs 初赛长视频）。**raw 语义能力没有证据失效，只是被计分规则
   和域变化掩盖**。
4. **k_size 取消（10-05 规则巨变）的战略红利一天都没吃过**：取消后「大语义模型
   管线不再受罚，唯一约束=参数 ≤9B」。我们的应对却是在 450M 冻结特征+9M 头上
   连换三种监督（PHD2/Mr.HiSum/QV）——平台分 34.9-35.2 纹丝不动，证明瓶颈根本
   不在监督信号，而在**管线里没有一个模型真正「看懂」视频**。
5. **模型选型问题（用户三问之三）——答案：是，但精确形态是**：
   不是「450M 太小」这种泛泛之谈，而是 **9B 参数预算花错了地方**。初赛两大杠杆
   （+8.41 空间点位、+4.01 时间清理）全是教师语义能力的产物；复赛合规预算 ≤9B，
   我们却把预算花在 9M 的排序头上（参数上无所谓的组件），从未把 7-9B VLM 放进
   提交链。AHA（8.63B，合规）资产 10-08 已全部落盘却在挂起。

## 4. 三问直答

- **为什么会这样**：初赛的正确结论（语义管线=涨分机器）在复赛被 k_size 压制的
  教师回分误判否定；12 轮全部投入排序头内卷；k_size 取消后没有回头重测前提。
- **还差什么**：差的是「语义级帧判断」整体缺失，不是排序精度。9.83 分 ≈
  教师时间清理(+4.01) + 教师级点位与 B3 蒸馏头的残余差距 + 语义排序，在复赛
  集的等价物。
- **是不是模型选型**：是。≤9B 预算下应选「7B VLM 语义管线」，我们选了
  「450M 特征 + 9M 排序头」。
