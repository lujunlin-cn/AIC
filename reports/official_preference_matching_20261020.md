# 官方偏好匹配研究（2026-10-20）

## 问题定义

假设官方评测集的来源、事件类型、标注政策或高光密度与 PHD2、YouTube Highlights 等公开数据不同，公开数据上的排序提升就可能无法迁移。目标不是从官方总分反推出测试真值，而是识别一组可迁移的决策结构，并用源级留出和少量预注册官方对照验证它们。

官方总分只有一个视频宏平均标量。对一个提交包的分数变化，只能识别该包改动在测试集上的平均效用差，不能识别：

- 哪些具体视频有高光；
- 哪些具体帧是真值；
- 官方正例密度或空视频比例；
- 某个公开数据源与官方集合的逐视频对应关系。

任何用回分挑选测试视频、构造伪标签、调逐视频阈值或恢复 GT 的做法都不进入研究路线。

## 已有官方证据约束出的“偏好形状”

下表只使用已经记录的成对提交结果，作为机制证据，不当作测试标签：

| 观测 | 结果 | 可支持的窄结论 |
|---|---:|---|
| CENTER_EXACT085_B3 vs AHA 精确预算 | `36.04 vs 35.07` | 当前强位置先验胜过未经目标域适配的通用高光判断 |
| R54 中心残差 | `36.22` | 小幅视频级相位修正可能有用，仍保持连续窗口 |
| R71 自适应预算 | `36.43` | 官方集合上的预算/分母政策可能与公共视窗不同；机制尚未识别 |
| R70 空间 utility | `36.42` | 原生 crop 监督有官方迁移信号，空间证据强于时间代理 |
| R107 生命周期时间 | `36.43` | 事件阶段概念没有超过连续中心父链；公开代理增益未迁移成突破 |
| R93 4fps端点 | `36.32` | 更密观测可能有小增量，但当前低分辨率合同没有突破 |
| R108 采样分歧 | `35.62` | 观测不一致本身不是高光价值，可能只是噪声或边界不稳定 |
| R91 TVSum+ResNet18 | `33.87` | 通用摘要监督和目标域时序迁移不匹配；不能归因于参数规模本身 |
| R69 分段门控 | `24.95` | 轨迹稳定性和官方逐帧 IoU 不是同一个目标 |
| R82 外部空间 utility 驱动时间 | `36.20` | 公共空间排序改善不能直接用来重排官方时间集合 |

这些结果共同支持三条有限判断：

1. **连续集合是重要先验。** R54、R71、R107 的高分都保留了中心锚定或有限相位修正；大幅后移和碎片化替换风险高。
2. **目标域监督比模型大小更关键。** R91 的小模型负结果不能推出小模型无效，只能说明 TVSum 摘要目标、ResNet18 表示和当前解码合同不匹配。
3. **时间与空间必须联合考虑。** R70 的空间代理和官方结果方向一致，R82 的外部空间排序虽正但官方下降，说明时间重排使用的 utility 必须对应最终输出框。

这些证据不能识别官方究竟偏好“动作完成帧”“事件高潮”“中心位置”还是某种隐藏的高光密度。它们只给出了部署时应该保留的安全结构。

## PHD2 等公开数据与官方偏好的差异模型

把来源名称直接作为域标签还不够。更有用的是按可能改变标注政策的变量建模：

- 视频长度和事件密度；
- 固定机位、第一人称、运动相机、剪辑视频；
- 事件是动作完成、结果揭示、人物反应还是连续表演；
- 主体尺度、多人比例、画幅和字幕/水印；
- 镜头切换率、动作速度和事件持续时间；
- 是否需要前后过程才能判断；
- 高光是否集中在一个连续区间。

PHD2 主要提供用户制作 GIF 的行为，YouTube Highlights 提供 MTurk 保留片段，R42 提供少量 AIC-like 人工阶段和信息依赖标签。它们不应被拼成一个统一硬标签，而应被视为同一潜在“选择政策”在不同观测和标注机制下的三个带噪投影。

## 不依赖官方标签的匹配方法

### 1. 分层监督，而不是伪统一标签

建立共享视觉/时序表示和数据集特定读出：

- PHD2：user interval、vote density、unobserved mask、同视频 pairwise；
- YouTube Highlights：MTurk soft votes 和同视频 pairwise；
- R42：`generic_highlight`、`event_phase`、`information_dependence`，只作为低权重辅助目标；
- 其它摘要数据：只作预训练或负对照。

主损失学习同视频候选的相对效用，辅助损失学习阶段和信息依赖。这样允许不同来源的尺度和缺失机制不同，模型仍可共享事件结构。

### 2. 用源级外推检验“官方偏好”假设

模型选择不看 pooled frame metric，而看以下组合：

- PHD2 source-held-out；
- YouTube Highlights domain-held-out；
- R42 source-held-out 的阶段/高光校准；
- 最差来源和最差事件类型的退化；
- 固定输出预算下的集合效用，而非单独 AP/Spearman。

一个候选只有在多个来源方向一致时才说明它学到了可迁移政策。只在 PHD2 上变好，说明它可能只学会 GIF 制作过程。

### 3. 用有限动作空间保持官方安全先验

Valen 时序不直接生成任意帧号。先固定 R26/R54 的连续集合和预算，只允许：

```text
left / keep / right
```

Valen 选择窗口相位，程序负责原始帧映射。这样测试的是“内容是否能修正中心先验”，不会把模型错误扩大成碎片化输出。只有窗口 Choice 在多个来源通过，才研究边界或可变预算。

### 4. 做政策鲁棒而不是测试分布拟合

训练时采用来源均衡或最差来源约束，保留一个中心策略回退：

```text
J(video, window) = content_score + bounded_residual
```

当 Valen 置信度低、候选概率接近或候选排序受顺序置换影响时，回退到中心窗口。回退阈值只在公开源级验证集固定一次，不能用官方回分继续调。

不能用官方测试视频的无标签分布来重加权训练、挑选标签或调阈值；那仍然属于测试集适配。

## 最有价值的判别实验

当前空间 utility T006 完成后，按以下顺序执行：

### T0：Valen 时序零样本政策探针

- 同一视频构造 `left/keep/right` 三个同预算窗口；
- 固定 `delta`、候选顺序循环和视频帧数；
- PHD2、YouTube Highlights 分别统计 source-macro 窗口覆盖和 pairwise 选择；
- 加入 position-only、候选顺序置换和重复帧/邻帧控制；
- 记录 Valen 选择是否只是中心先验。

T0 只判断 Valen 是否有可利用的时序内容信号，不声称官方收益。

### T1：PHD2 目标域时序微调

- 从原始字段重建 soft-vote、user interval 和 unobserved mask；
- source-disjoint train/dev/test；
- 固定窗口候选和预算；
- 只训练决策 head/LoRA，保持视频输入合同；
- 用 source-macro 集合效用和严重退化率验收。

### T2：YTH 与 R42 的跨域确认

- YTH 只用 MTurk vote/pairwise，不把 weak match 当真值；
- R42 只作为阶段/信息依赖辅助或错误分析；
- 如果 PHD2 增益在 YTH 和 R42 方向相反，关闭该训练合同，不制作官方包。

### T3：单变量官方验证

只有 T1/T2 通过后，制作一个包：固定 R54 时间空间父链，只替换 Valen 的 bounded window policy。官方回分只用于判断这条政策是否迁移，不能再对结果做逐视频修改。

## 最可能改变路线选择的结果

| 结果 | 解释 | 行动 |
|---|---|---|
| PHD2、YTH 都超过位置基线，且候选顺序置换明显变差 | Valen 学到内容相关的相位政策 | 进行时序 LoRA 和单变量官方验证 |
| PHD2 提升、YTH 下降 | GIF/动作域偏差 | 不扩大 PHD2 训练；增加域特定读出或关闭该路线 |
| 两者都只复现中心位置 | 没有可识别内容增量 | 不训练 Valen 时序；保留中心父链 |
| PHD2/YTH 都提升，但官方包不升 | 公开偏好与官方标注政策不同，或空间—时间耦合错误 | 关闭公开偏好直接迁移，转向目标域可追溯监督和部署框效用 |
| 只有阶段辅助提升 | 事件结构比原始高光分数更可迁移 | 保留阶段辅助，减少逐帧 score 权重 |

## 当前判断

“官方有特殊偏好”是合理假设，但尚未被直接证实。现有官方证据更支持：官方偏好至少包含强连续性、中心/相位先验和稳定的空间构图约束；它是否进一步偏向完成瞬间、反应帧或某种视频子域仍不可识别。

最值得投入的路线是**目标域行为监督 + bounded window policy**：PHD2/YTH 学内容相对排序，R42 提供事件阶段辅助，中心连续集合作为结构先验，Valen 只做有限窗口 Choice。当前 Valen 空间 utility 结果出来前不启动时序训练。

本研究没有读取官方测试标签，没有用官方回分构造训练样本，也没有进行逐视频回分拟合。
