# A0_006 zero-parameter temporal post-processing

This report compares policies on the repaired A0_006 checkpoint.  The metric
is the versioned `TVSum temporal proxy` (`tvsum_summary_mean_norm_ge_0.5_v1`),
not AIC `F_video`; there is no spatial GT or official evaluator here.

Scores were produced from `/data/aic/experiments/A0_006/export/model_fp32.pt`
on the remote PyTorch 2.9.1 environment.  Feature logits use the same whole
sequence `lengths` path as training, rather than overlapping inference windows.
The development sweep was run on the 16-video `A0_proxy_v2/val_features.jsonl`
manifest.  The frozen local lockbox was evaluated separately using
`A0_proxy_v2/lockbox_manifests/test.jsonl` and a single preselected config.

| policy (fixed after dev) | dev macro F1 | lockbox macro F1 | lockbox F1 std | lockbox selection rate | lockbox empty rate |
| --- | ---: | ---: | ---: | ---: | ---: |
| raw, threshold 0.40 | 0.151875 | 0.114304 | 0.094871 | 0.085791 | 0 |
| Gaussian, window 5, sigma 1, threshold 0.40 | **0.154742** | 0.112405 | 0.085654 | 0.084310 | 0 |
| gap fill 4 + minimum run 2, threshold 0.40 | 0.152753 | 0.108842 | 0.086331 | 0.086354 | 0 |
| per-video rank percentile, threshold 0.90 | 0.146694 | **0.115942** | 0.086715 | 0.101018 | 0 |

The Gaussian development gain is only `+0.00287` and reverses on the lockbox,
so it is not promoted as a stable improvement.  Rank normalization has the
highest lockbox value among these preselected policies, but its development
value is lower and the lockbox contains only seven videos; it remains a
diagnostic challenger rather than a replacement for raw A0.  The raw policy
therefore remains the conservative engineering fallback until another
independent split supports a post-processing change.

Commands (remote, no lockbox tuning):

```bash
PYTHONPATH=. CUDA_VISIBLE_DEVICES=4 /opt/miniconda3/bin/python \
  scripts/evaluate_temporal_postprocess.py \
  --model /data/aic/experiments/A0_006/export/model_fp32.pt \
  --manifest /data/aic/features/A0_proxy_v2/val_features.jsonl \
  --output /data/aic/experiments/A0_006/postprocess_val.json --device cuda

PYTHONPATH=. CUDA_VISIBLE_DEVICES=4 /opt/miniconda3/bin/python \
  scripts/evaluate_temporal_postprocess.py \
  --model /data/aic/experiments/A0_006/export/model_fp32.pt \
  --manifest /data/aic/features/A0_proxy_v2/lockbox_manifests/test.jsonl \
  --output /data/aic/experiments/A0_006/postprocess_lockbox_raw.json \
  --config-json /data/aic/experiments/A0_006/postprocess_raw_v1.json \
  --protocol-role lockbox --device cuda
```

Implementation is `aic.postprocess`, with unit tests covering normalization,
shot-reset smoothing, hysteresis, gap filling, minimum duration, and invalid
window handling.  A lockbox invocation requires `--config-json`; the script
refuses a default sweep when `--protocol-role lockbox` is selected.
