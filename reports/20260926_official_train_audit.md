# Official training package audit (2026-09-26)

This audit covers the local package at `/home/hajimi2025/datasets/data-challenge-2026/video_highlight`. It is a challenge data package, separate from the historical `/data/aic/datasets` mirror. The package contains 33 `qvhighlights-videos-*.zip` shards and an extracted `train/source_videos` tree.

## Inventory

| item | observed value |
|---|---:|
| compressed train shards | 33 |
| compressed bytes | 129,307,586,280 B (129.308 GB decimal) |
| extracted train videos | 11,245 MP4 files |

The extracted tree contains 11,245 unique clip filenames. The annotation file references 863 unique source-video base IDs; 889 of the 987 referenced clip files are present locally. The annotation-linked files that are present occupy 10,161,788,582 B (10.162 GB decimal), so this is a labeled subset of the larger video archive rather than a one-record-per-file manifest.

## Provenance and label semantics

The only machine-readable provenance is inside each annotation record:

- `provenance.source = QVHighlights`;
- `schema_version = seed_weak_training_label_v1`;
- `seed_model = api_doubao_doubao-seed-2-1-pro-260628`;
- `prompt_version = seed_temporal_compact_v2_20260812`;
- `annotation_mode = temporal_spatial`.

All 987 records have temporal segments and teacher timeline signals. Spatial observations are heterogeneous: 624 records contain seed `cropRois`/`crop_keyframes`; 363 have empty crop arrays with `quality.spatial_source = dropped_center_default`. These are seed/weak labels generated by the recorded teacher process, not native human QVHighlights frame/crop ground truth. They must be versioned as a separate target and should not be silently mixed with TVSum summary proxy labels.

The package has no README, license file, source manifest, or license field alongside the shard archives. Therefore the current evidence supports the description **challenge-provided QVHighlights-derived training package**. It does not independently establish a public QVHighlights license for every downloaded video. Keep the source and label provenance in experiment manifests and disclose it according to the competition rules.

## Relation to prior experiments

The frozen A0/DeiT experiments used 27 TVSum train videos (366,499,017 B, 6,732.26 s, 187,216 frames) and did not use this package. Relative to the 129,307,586,280 B compressed challenge train archive, that is approximately 0.283% by bytes. The current historical models therefore provide no evidence about scaling on this package.

The remote `/data/aic` inventory does not contain these 130 GB of shards; it contains the older TVSum/SumMe/DHF1K/RetargetVid assets and cached features. Any full-data experiment must explicitly import this package (preserving `train`/`val` source isolation and the weak-label version) before training.

## Reproducible importer output

`scripts/prepare_qvh_training_manifest.py` was run successfully against the
package and produced the external (non-Git) manifest at
`/home/hajimi2025/datasets/data-challenge-2026/qvh_manifest_v3/`:

| split | verified clips | duration | decoded frames | bytes | audio |
|---|---:|---:|---:|---:|---:|
| train | 800 | 33.208 h | 3,332,294 | 9,176,418,577 B | 800 |
| val | 89 | 3.703 h | 375,217 | 985,370,005 B | 89 |

The 98 missing annotation-linked clips remain represented in
`inventory.jsonl` with `download_status=missing`; they are not silently moved
to another split. The importer writes frame-aligned continuous labels to
`labels/*.npz` under protocol `qvh_seed_timeline_linear_v1`, plus a canonical
`dataset_manifest.jsonl` accepted by `aic.data.read_manifest` and a
cache-builder manifest (`cache_manifests/train.jsonl` and `val.jsonl`). The
labels are explicitly weak seed supervision (`official_aic_gt=false`) and are
not comparable to TVSum human summary importance without a separate evaluator.

The package archive contains many unlabeled extracted clips (11,245 total),
while only 889 clips are linked by the 987 annotation records. Therefore a
“100% official data” experiment must state whether it means the full archive,
the verified labeled subset, or an explicitly defined unlabeled pretraining
stage; this audit does not treat unlabeled clips as supervised examples.
