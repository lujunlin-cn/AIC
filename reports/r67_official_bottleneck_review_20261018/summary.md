# R67 官方回分后的系统瓶颈复盘（2026-10-18）

## 结论先行

R67=`36.16`，R54=`36.22`，R26=`36.04`。R67 相对 R54 只改了 2,427 个入选帧（81/426 个视频），使用同一 2fps、高分辨率 TimeLens2 区间、同一 V9 vision-only 构图框和同一精确 85% 预算；分数下降 `0.06`。因此，V9/R26 构图分歧作为逐帧价值信号没有得到支持。

当前主要瓶颈应表述为：**域迁移导致的时间集合决策失配**。近端表现是时间选帧错误，根因更可能是公开标签/教师区间与复赛测试标注政策不一致。模型容量没有被现有回分证明为瓶颈。空间框是高杠杆基础组件，但当前没有证据证明 V9 的小幅替换能改善 R54；预算 85% 已处于局部较优区间。

|---|---|---:|---:|---|---|

## 主要解释的证据强弱

### 1. 时间集合决策：已确认是最敏感的近端瓶颈

在空间框固定为 R26 B3 的实验中，R43 相对 R26 下降 `1.09`，R46 下降 `0.16`；R44 仅上升 `0.05`。在 V9 空间固定的 TimeLens 家族中，R57 相对 R54 下降 `1.46`，R59 下降 `1.18`，R67 下降 `0.06`。同一 85% 预算下，时间集合的少量错误即可改变分数，统一位置平移或密集边界替换会造成约1分级损失。

但这不表示“应该继续换更大的时间模型”。R39–R43 的高容量或内容启发式时间路线均低于中心先验；R54 是唯一正向联合结果，且其变化近似视频级连续窗口，而非逐帧高光排序。最安全的时间决策仍是中心85，只允许小幅、视频条件化的残差。

### 2. 域迁移/监督错位：最可能的根因

同一公开18视图代理对不同路线给出的排序与官方回分不一致：

| 候选 | 公共代理相对中心 | 官方相对相应锚点 |
|---|---:|---:|
| R44 | 约 +0.0209 | +0.05 vs R26 |
| R46 | +0.0228 | -0.16 vs R26 |
| R54 | +0.0250 | +0.18 vs中心（但含V9框） |
| R57 | +0.0325 | -1.46 vs R54 |
| R59 | +0.0365 | -1.18 vs R54 |

该五点不是独立统计样本，不能计算泛化相关系数作为结论；它们足以显示“公共代理越高，官方越高”在本轮不成立。特别是 R57/R59 的公共正增量与官方大幅负增量，说明标注源、视频域、教师输入合同和官方构图联合目标之间存在迁移失配。

因此，时间错误是表现层，域/监督合同失配是首要根因候选。继续在同一12源标签上提高代理，预计不会可靠提高官方分。

### 3. 空间框：高杠杆基础组件，但当前改进方向未知

R25 的同一帧集合上，B3框相对中心框提高 `4.95` 分，说明错误构图会大幅压低联合分；这条证据支持保留 B3/V9 级别的空间模型。另一方面，R54 与 R67 使用同一 V9框，R67 仅通过空间分歧改变时间集合且下降 `0.06`，不能说明 V9 框本身优于 R26 B3。V9/R26 全帧平均框 IoU 约 `.998`、选中帧约90%几何差异为零；继续利用无标签框分歧做选帧已经被 R67 削弱。

当前缺少的不是更大的空间 backbone，而是同一官方源上的 native crop GT 或一个合法的空间隔离回分：`R47_V9_B3_CENTER85` 与 R26 同一中心时间集合，只改变 V9框。没有这项证据，不能把 R54 的 `+0.18`归因空间，也不应继续扫 V9分歧规则。

### 4. 预算决策：局部已接近最优，不是首要阻塞

center75、center95 都低于 center85，精确预算修正只带来 `-0.11`（AHA条件）。当前 R54/R57/R59/R67 全部使用完全相同的精确 85%预测数 `199,037`，而官方分差达到 `1.46`；因此剩余问题主要是集合内容和域迁移，而不是预测数量。

## 需要停止和保留的路线

- 停止 R39–R41 新颖性/冗余/门控扫参、R43事件完成度替换、R46/R48低级RGB残差微调、R57统一后移、R59低分辨率4fps端点集成。
- R67 不支持把 V9/R26分歧当作高光价值，但 R54仍保留为最高分锚；R26保留为低参数安全锚。
- 不把公共人工标签代理增量升级为官方收益；R44的 `+0.05` 只记为弱正。

## 下一步优先级

1. **先完成空间隔离证据**：获取/提交 `R47_V9_B3_CENTER85` 的真实回分，识别 R54 的 `+0.18` 中有多少来自 V9；这项信息价值高于继续设计分歧排序。
2. **若 V9 与 R26 接近或下降**：冻结 V9/B3空间，转向同一高分辨率2fps TimeLens输入上的视频条件化、小幅残差；保留中心85为低置信回退。候选必须限制在小交换率和连续窗口内，不能全局平移或低分辨率重跑教师。
3. **若 V9 明显提升**：优先研究 native crop utility 的可学习监督和 portrait/landscape分层，不再用无标签几何变化充当高光代理。
4. **域迁移是新训练的准入条件**：新增路线必须有源级隔离、真实视频域匹配和联合时间—空间目标；公共12源代理仅作否决工具，不能作晋级依据。
5. **保持预算85%**：没有新证据前不再提交 keep/预算扫描。

## 证据边界

官方没有逐视频 GT。本报告不能识别 R54 的时间、空间和交互贡献，也不能从总分反推出测试标签。R57/R59 共享 V9框且大幅失败，足以否定两种具体时间解码配方，不足以否定所有语义时间信号；R67的 `-0.06` 足以削弱无标签空间分歧选帧，不足以证明任何单一构图框最优。
