# 复赛分数滑退归因与激进改造计划（2026-10-01）

**输入**：复赛官方分（用户 10-01 告知）——Qwen32B 教师 34.84、V8-B3 学生 34.75、V7 学生 33.82。
**初赛参照**：教师系最佳 INTERP 48.67（174 视频集，raw 口径）。
**方法**：官方分数账本（registry.jsonl 17 条官方记录）× 迁移矩阵 × 复赛集 426 视频元数据实测 × 数据资产盘点。所有反推均标注假设。

## 1. 滑退分解：不是模型退化，是三重叠加

### 1.1 复赛计分公式变了（规则 §3.4/§4）

- 初赛：`Score = 100 × F_video`（raw，不乘系数）。
- 复赛：`Score = 100 × F_video × k_size`，k_size 按**权重文件解压后字节**：≤100MB→1.00，100–500MB→0.95，500MB–9GB→0.90，**>9GB 超限（规则原文：可判该次提交无效）**。

### 1.2 三包 raw 反推（假设平台 k_size 表与规则一致）

⚠️ **更正（10-01 夜）**：学生包权重 903,812,857 B = **861.94 MB**（2^20 口径），落在 **500MB–9GB 档 → k_size = 0.90**，不是 0.95。（0.95 只适用于 100–500MB 档。）下表按正确档位重算：

| 包 | 权重 | 档位 | k | 官方分 | **raw F_video 反推** |
|---|---|---|---|---|---|
| 教师 32B | 62.1 GB | **>9GB 超限** | 未知 | 34.84 | 38.71 (k=0.90) ～ 48.39 (k=0.72) |
| V8-B3 | 861.9 MB | 500MB–9GB | **0.90** | 34.75 | **38.61** |
| V7 | 861.9 MB | 500MB–9GB | **0.90** | 33.82 | **37.58** |
| B0（锚点，未提交） | 0.2218 MB | ≤100MB | 1.00 | — | 平台分即 raw |

**教师一行未改（同权重/同 prompt/同机制），从 48.67 掉到 34.84**——模型没有退化，掉分来自 k_size 加权 + 可能的集难度差。

### 1.3 蒸馏缺口的正确表述：取决于教师的 k，区间 [0.1, 9.8] 分

学生 B3 raw = **38.61**。教师 raw 随其超限档系数变化：

| 教师 k（假设） | 教师 raw | B3 缺口 |
|---|---|---|
| 0.90（与学生同档，平台宽容处理） | 38.71 | **+0.10**（基本持平） |
| 0.85 | 40.99 | +2.38 |
| 0.80 | 43.55 | +4.94 |
| 0.72（使 raw≈初赛 48.67） | 48.39 | +9.78 |

**不能再把缺口说成"12 分"**——那是基于错误的 k=0.95 假设。可确定的是：**在教师拿到与学生相同系数（0.90）的情形下，450M 学生已经基本追平 32B 教师**（38.61 vs 38.71）；缺口的上界由 B0 锚点包收窄。

### 1.4 判别实验（P0-1，已打包）

B0 的 k_size 被钉死在 1.00，所以 `B0_复赛 / 34.42` = **难度比**，进而 `教师 raw 隐含 = 34.84 / 难度比 / k_教师`。这能把上表的 k 未知区间收窄到一个范围。包已交付（`LFM_B0_SEMIFINAL.zip`，sha256 `c055917b…94cb`）。

### 1.4 合规风险（必须告知）

- 规则原文：>9GB **可判无效**；model_size_mb 缺失**可直接判无效**。本次平台对三个包（均无 model_size_mb 字段、教师 66.7GB）都给了分，说明平台当前未执行，但"填报与赛方核验不一致时以赛方核定值为准"——**教师包 34.84 存在被追溯风险**。后续主攻学生包；教师包降级为研究对照。

### 2.2 统计结论

1. **类别间迁移率差异极端**：教师点位/时间掩码类 5/5 正迁移；空间几何/空间学习类 0/6。Fisher 精确检验 one-sided p = 1/C(11,5) ≈ **0.002**（样本量小，探索性，但方向一致且无反例）。
2. **本地→官方秩相关**：教师轴 ρ=1.0（NOFACE>DENSE>INTERP 在两侧秩序一致）；空间学习轴 ≤0（三次本地全正、官方全负）。**"验证集涨官方也涨"这条底线，只在教师点位轴成立；空间学习轴的本地验证集事实上失效**。
3. **时间轴红利远未挖完**：只删 10% 帧就 +4.01。此后 6 轮再没有动过时间行（全选至今）。InternVideo2 失败被错误归因为"时间路线不行"，实际是 QVH 弱标签域不对齐——**同域的 PHD²（见 §3）当时不在盘上**。
4. **学生轴唯一官方确认的有效杠杆是数据量×域覆盖**（B3−V7 +0.93，归因 LIVE 10×+旋转增强）。

## 3. 数据侧审计

**干净度：合格**。LIVE/RV 走冻结版+SHA+暴露台账（holdout_exposure_v1），RetargetVid 200 全暴露只作 exposed_eval，PHD² tier0 831 官方 test 宿主已隔离不入 fit——防泄漏制度在 8 轮里没有破口。

**对齐度：不及格，且是最大可修复项**：

1. **官方评测域 = PHD² 域**（清单：tier0=831 "官方 test 的 is_last GIF 宿主"；PHD-GIFs = YouTube 视频 + 用户 GIF 高光，ACM MM'18）。而我们空间训练域 = LIVE（广播级 1080p 横屏合成竖窗）+ RV（DHF1K 源）。**域差 = 本地空间验证失效的根源**（§2.2 结论 2）。
2. **PHD² 13,939 视频 / 120,833 条高光标注已在盘上，从未进任何训练**。aic_split train 109,710 / val 10,226。tier0 防泄漏已设。这是同域时间监督的最大金矿。
3. 空间 GT 依然稀薄：RV 200 视频（全暴露）+ LIVE 合成窗（无真实裁剪 GT）。portrait_reframe_pilot_v1（320 源人工竖屏裁剪标注）仍 pending_annotation——**28% y 轴任务至今没有一个真实 y 轴 GT 训练样本**。
4. 闲置资产：ClipShots 5,917 转场（shot boundary，B0 路径的镜头 reset 可换学习式转场）、DHF1K/DAVSOD 显著性（y 轴目标的域内显著性）、YTH 963 标注。

## 4. 模型侧审计

1. **头容量不是瓶颈**：1.5M 头对 129 候选打分，V7 seed 间 S-dev 差 0.011（稳定），unfrozen 24M 臂 600 步震荡下行 = **数据不足以支撑更大参数**，不是头太小。
2. **瓶颈一：冻结 LFM 表征的定位信息**。LFM450 零样本空间 ≈B0、−0.06 vs 教师——表征本身的主体定位能力弱于 32B 教师；头只能在冻结表征上做线性/浅层映射，天花板被表征锁死。
3. **瓶颈二：结构丢空间细节**。win/out token-mean 池化把 22×40 token 网格压成 2305-d 向量，主体位置的细粒度信号在池化中稀释；教师点生成则保留完整 2D 注意力。
4. **训练策略**：1200 steps×B16（4.5k 样本 3.2 epochs）头训练收敛充分；KD 方向正确（V8 KD-v2 独立损失项两池显著）但 β 幅度小一个量级——**教师信号还有未兑现增量**；V8 值头 STEP 300 过拟合 = 域内样本多样性不足的信号。
5. **部署链仍继承 B0 的 1s 关键帧网格 + hold/EMA 传播**；教师 INTERP（+0.79）证明点间传播有价值，学生窗 hold 策略在短视频快运动下帧间漂移更大。

## 6. 激进改造计划

### P0（48 小时内，判别 + 摘低垂果实）

1. **B0 复赛锚点包**：打包 `/data/aic/semifinal_20261001/B0/predictions.jsonl` 提交（今日配额剩 2 次）。用它判别集难度与教师 k_size 情景，同时校准"本地 vs 官方"基线锚。
2. **TCN 时间头复活**：V6 T1 配方（740,609 参数，3/3 预注册门全过、YTH 迁移 indicative）+ **PHD² train 10.9 万标注**重训；输出保持 TEMP 式"只删不增"掩码（保底逻辑：宁可全选不误删）。选择集 PHD² val 10,226。这是时间轴 +4 分红利的第一次真正开采。
3. **教师竖源诊断**：抽 30 个竖源→16:9 视频人工核查教师点位（教师 prompt 全程横屏时代设计，竖源下可能系统性偏移）；若确认偏移 → portrait 特化 prompt 二 pass 补点。

### P1（下周，主攻学生蒸馏缺口）

4. **教师伪标签规模化**：教师点+窗口分在 LIVE 1,466 全量 + PHD² 采样 3–5k 视频打点（0.70 qps → ~10 万查询 ≈ 40h NPU，一人作业可过夜跑）；学生 KD-v2（β=0.3，两池已验证显著）大规模重训。**沿 B3−V7 +0.93 已确认的"数据量"轴加码**。
5. **头结构重构**：token-mean 池化 → 显式热图头（22×40 token 逐 token 回归最优窗隶属概率，窗口分=热图积分），保留 2D 空间结构；同步跑 cross-attention RoI 对照臂。
6. **y 轴本地验证集**：LIVE 旋转合成竖源→16:9 任务 + PHD² 竖源子集，建"复赛镜像验证集"（时长 p50 14s、横:竖:方=66:29:5、目标比例构成 43/25/28/4）——修复空间轴本地验证失效。
7. **解冻升级**：LoRA（r=8，只挂 attention q/v，低 lr）+ 伪标签大数据；对照 V7 全解冻失败的教训（600 步震荡 = 数据不足）。
8. **推 portrait_reframe_pilot_v1 标注**（320 源真实竖屏裁剪 GT）——28% y 轴任务的真实监督。

### P2（激进备选）

9. **Qwen2.5-VL-3B 底座替换**：原生 grounding（RefCOCO ~73.7%）+ k=0.90。回本条件：raw ≥ 450M 包 raw×1.056（现 36.58 → 需 ≥38.6）。教师 raw 上限 ~48 说明空间点位上限远未到；3B 蒸馏后有真实机会。先跑零样本点位在 RV/复赛镜像集的对照。
10. **GRPO 后训练**：候选窗选择=策略、IoU=reward、教师点=参考策略；RL on grounding 已有 VLM-R1 先例。
11. **时间×空间联合部署**：TCN 时间分 gate 低价值帧 + 空间头 + TTA。

## 7. 一句话回答用户三问

- **数据干净吗**：干净（冻结版+暴露台账无破口），但**域不对齐**——官方域是 PHD²（YouTube/GIF），我们训练域是 LIVE/RV；同域的 PHD² 12 万标注闲置至今是最大浪费。
- **验证集对齐了吗**：教师点位轴对齐（本地-官方秩相关 1.0）；**空间学习轴不对齐**（6 次本地涨、官方全不涨，p≈0.002）——这就是要建"复赛镜像验证集"的原因。
- **模型/训练**：头容量与收敛不是瓶颈（种子稳定、1200 步充分）；瓶颈是冻结表征的定位信息 + 空间 GT 稀薄 + 时间轴 6 轮没动过。**复赛计分下学生包是主战场**：B3 raw 38.61 与教师在同档系数下的 38.71 基本持平，而教师包还有超限被判无效的合规风险。
