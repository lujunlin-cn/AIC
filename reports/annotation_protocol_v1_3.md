# 高光视频打标标准 V1.3

生效日期：2026-10-17。给甲、乙两位打标人员使用。先读「开工速查」，第一次遇到拿不准的情况再查后文。

## 开工速查

**我们标的是：图片对应的这一时刻，有没有值得保留的事件或信息。**

不是选最漂亮的一张，不是给人物画检测框，也不是每个视频必须选出几个高光。

1. **进自己的项目。** 甲用「标注员甲」，乙用「标注员乙」。不要进入对方项目，不要交换具体答案或截图。
2. **先看视频。** 每换一个视频编号，先完整播放上方30秒视频，打开声音。同一个视频看过一遍即可，后面可以回放。
3. **看当前图，给等级。** 没有特别内容＝0；只是交代背景或普通过程＝1；有明确值得保留的内容＝2；事件的关键动作、结果、揭示或突出反应＝3；证据不足＝不确定。
4. **填阶段、类型、判断把握。** 普通动作也有阶段和类型，没有高光不等于没有事件。
5. **只有2/3再填信息依赖和构图。** 判断价值需要看什么；然后画**一个完整保留窗口**，填画框理由和构图把握。没有合理窗口可以不画，但要选「低或无合理框」。
6. **提交。** 不要只关页面；提交后再做下一题。每做完一个视频可休息一下。

**没有名额和比例要求。** 整段都普通，可以全0/1；精彩动作持续几秒，那几张图可以连续都是2或3。不要为了少选、去重或凑比例改等级。

## 1. 我看到的是什么

每个视频截取了30秒，每秒取一张图片，所以一个视频有30题。标题中的「图片在片段第几秒」对应播放器时间；「源素材时间」只是研究记录，不需要换算。

这30秒是你可以使用的全部上下文，不是原始长视频全片。如果关键事件发生在窗口之外，不要补剧情；若因此无法判断，选「不确定」，把握选「低」，备注「事件超出片段」。

视频声音无法播放时，先检查静音和音量；仍无法播放，在备注写 `audio_unavailable`。听不懂语言写「听不懂语言」，不要凭嘴形猜台词。可见内容已经足够判断的帧仍可正常打标；受影响的帧选「不确定」和「低」。

只看本项目提供的视频与图片。不要找原数据集的搜索描述、原标签、模型预测，也不要看另一人的答案。

## 2. 给等级：按这个顺序判断

先用一句话说清：**「这一时刻发生了什么，为什么值得保留？」** 然后按下面的流程选。

```text
现有图片、前后过程和声音，够不够判断？
├─ 不够，而且缺的信息会改变等级 → 不确定；把握选低，备注缺什么
└─ 够
   ├─ 只是等待、空镜或普通状态，没有特别事件/信息 → 0普通
   ├─ 有背景、准备或普通过程，但保留价值低 → 1有信息
   └─ 有明确值得保留的动作、变化、互动、信息或场景
      ├─ 能表达有价值的内容 → 2值得保留
      └─ 正在表达事件的关键部分、突出结果或核心信息 → 3高光核心
```

| 等级 | 通俗解释 | 虚构例子 |
| --- | --- | --- |
| 0普通 | 看得清，也能确定没有特别内容。 | 比赛间隙在场边等待；没有变化的普通墙面。 |
| 1有信息 | 交代谁、在哪里、准备做什么，或是普通过程。 | 调整工具准备演示；普通地走向讲台。 |
| 2值得保留 | 有一件说得清、值得保留的内容。 | 清楚展示一个有技巧的动作过程；展示有解释价值的实验变化。 |
| 3高光核心 | 这一刻直接承载关键动作、结果、揭示或突出反应。 | 关键救球；实验结果首次显现；说出重要结论的时刻。 |
| 不确定 | 证据不足，无法可靠区分等级。 | 结果被挡住，成功与失败会导致不同判断；关键信息只在听不懂的讲话中。 |

### 最容易混淆的几种情况

- **0和1：** 0是确定普通、几乎没有保留价值；1是有背景或过程信息，但价值低。二者都可以是非高光，不用刻意寻找隐藏意义。
- **1和2：** 能描述画面还不够。能否指出具体的保留理由？「人在走路」通常只是描述；「走路中突然避开倒下的物体」才有明确变化。普通动作也可能在特殊语境中有价值，以实际证据为准。
- **2和3：** 2是值得保留的内容；3是正在表达关键部分。不要只因为附近还有更强的一帧就把本来有价值的帧降到1。结果并不天然高于过程：一个难度很高的动作过程也可能是3。
- **不确定和0：** 「没看懂」不等于「没高光」。先回放；仍缺关键证据就选不确定。
- **画质和等级：** 清楚、居中、颜色好看、镜头移动大，都不能单独证明高光；模糊也不能自动抹掉可辨认的关键事件。模糊到无法辨认时才考虑不确定。
- **相邻图片很像：** 分别判断时刻价值。只要同一关键动作还在发生，两张都可以是3，不因重复强行降级。不复制整段答案，阶段和内容可能已经改变。
- **说话、风景、慢镜头：** 不要求有运动才是高光。重要结论、罕见场景或有明确展示价值的画面也可以是2/3；普通讲话或普通风景也不自动是高光。
- **开头和结尾：** 位置本身不决定等级；不要默认中间精彩、两端普通。

没有固定数量或占比，也不要求每段都出现3。等级只表达当前时刻的内容价值，不要求你决定最终短片长度。

## 3. 填「事件阶段」

选择当前图对应的主要阶段。没有高光时也要正常填写。

| 选项 | 怎么判断 |
| --- | --- |
| 铺垫 | 还在准备、介绍背景，主要动作/信息尚未展开。 |
| 进行中 | 动作、互动或信息正在展开。普通走路也可以选进行中。 |
| 完成或结果 | 动作刚完成、结果被展示，或关键状态/结论被揭示。 |
| 结果后反应 | 结果已发生，现在主要看到表情、庆祝、惊讶、掌声等反馈。 |
| 无事件或无法判断 | 确实没有可辨认事件，或无法判断阶段。 |

**「结果后反应」不是「前一个动作之后的所有画面」。** 运动员落地后的正常走动一般仍是动作过程；落地后举手欢呼才是结果后反应。若结果与表情同时出现，按当前主要内容选一种。

## 4. 填「事件类型」和「判断把握」

事件类型只选当前主要的一类：

- **动作：** 人、动物或物体正在做事。
- **结果或揭示：** 重点是成功/失败、变化结果或新状态的出现。
- **情绪或反应：** 重点是喜悦、惊讶、失望或观众反馈。
- **人物互动：** 重点是人之间的配合、交流或关系。
- **信息或字幕：** 重点是结论、讲解、文字或屏幕内容。
- **视觉奇观或场景：** 重点是场景本身的展示价值。
- **其他：** 能说清是什么，但前面没有合适类别；备注一句。
- **无事件：** 没有可辨认的事件或信息。不要因为等级为0/1就统一选无事件。

判断把握与精彩程度分开：

- **高：** 看得懂，也比较确定这个等级。
- **中：** 大体明确，在相邻等级或事件阶段上有些犹豫。
- **低：** 缺证据，或歧义明显。等级为「不确定」时必须选低。

等级3也可以只有中等把握；等级0也可以是高把握。

## 5. 只有2/3填写「信息依赖」

这项问：**为了知道这一时刻为什么值得保留，最少需要哪种证据？**

它不问「你是否看过视频」。所有人都先看视频，看过后仍可选择「当前帧足够」。

| 选项 | 什么时候选 | 虚构例子 |
| --- | --- | --- |
| 当前帧足够 | 单看这张图就能指出具体的价值；不用猜前后结果。 | 清楚的罕见天象；图中文字已清楚给出关键结果。 |
| 需要前后过程 | 要比较前后状态，或看动作怎样完成，才能知道价值。 | 必须看接球前后才知道是否成功；看前后对照才知道修复是否完成。 |
| 需要声音或语言 | 核心价值来自台词、语气、掌声、叫喊或其他声音。 | 重要论点只在讲话里；笑点只在听到包袱后成立。 |
| 无法判断 | 看完片段仍说不清所需证据，或关键证据不可得。 | 价值可能在听不懂的讲话里，也可能在画面中，无法确定。 |

两种都需要时，选「需要声音或语言」，备注「同时需要前后过程」。看得懂的字幕已经把价值完整写在图片上，可以选「当前帧足够」。仅能认出人物/物体，不代表已能解释精彩之处。

0/1直接跳过本项，不确定也可以跳过并在备注写缺什么。旧结果已有本项不用为了格式而批量删除。

## 6. 只有2/3考虑画框：一帧一个窗口

**把框想成剪下来后，观众最终看到的整张画面。**

这批框不限制长宽比例，可以接近整张图；不用把每个人或物体紧紧圈出来。框要保留解释高光所必需的内容，并留适当空间。

### 画框步骤

1. 先想：观众必须看到哪些主体、物体、动作空间、结果或文字？
2. 在四种框标签中选最主要的一种：「主体」「多人或互动」「整体画面或景别」「字幕或屏幕信息」。**四个标签是同一个窗口的四种理由，不是要求画四种框。**
3. 拖出**一个**完整窗口。涉及两个人或人和物的关系，一起放进一个框；不要分别框脸、手、物体或字幕。
4. 在「画框理由」勾选实际需要的内容，可以多选；再填「构图把握」。
5. 检查是否误画了第二个框或一个小点。误框要选中后用删除工具移除；改框时移动/缩放已有框，不另叠一个。

### 框应该保留什么

- 接物、操作、运动：保留相关主体、关键物体和理解动作所需的空间；不要只框脸。
- 多人配合：保留相关参与者和关系；不要求把所有无关路人都放进去。
- 重要字幕/屏幕：若文字承载价值，要完整保留相关文字；无关水印不必强留。
- 场景展示：窗口可以覆盖大部分或整个画面，不强迫找到一个人当主体。
- 有多个合理窗口：只选你最愿意保留的一个，另一种选择写在备注里，**不要画第二个**。

构图把握：高＝合理窗口明确；中＝大致合理但边界/取舍有歧义；低或无合理框＝裁剪取舍困难，或无法给出稳定窗口。若有框且把握低，备注为什么；若没有合理框，不画，选「低或无合理框」，备注原因。

0/1或不确定不画框，画框理由和构图把握可跳过。**不好裁剪不等于不精彩**，不要为了少画框把2/3改成0/1。

## 7. 八个练习例子

下面都是虚构情况，不是本批次答案。同类画面需要按具体内容判断。

| 情况 | 等级与其他字段示例 |
| --- | --- |
| 人在等电梯，没有变化 | 0；无事件或无法判断；无事件；高。跳过依赖和框。 |
| 安装工具、准备演示，没有特殊操作 | 1；铺垫；动作；高。跳过依赖和框。 |
| 正在展示一项有技巧、可看懂的动作 | 可为2；进行中；动作；依赖按实际证据选。一个窗口保留相关身体和器材。 |
| 连续3秒都清楚展示关键救援动作 | 3张都可以3；分别填实际阶段。不因相似而只留一张，也不把「救援成功」当作已知事实。 |
| 球是否接住必须看前后才知道 | 若前后证实该时刻有关键价值，可为3；需要前后过程。仅凭静态姿态不能选当前帧足够。 |
| 人在讲话，关键结论只在语音中 | 理解并确认结论重要时可为2/3；信息或字幕；需要声音或语言。听不懂且无法从画面判断时选不确定、低。 |
| 成功后观众欢呼，画面主要是反应 | 可为2/3；结果后反应；情绪或反应。若必须听欢呼才能理解价值，选声音或语言。 |
| 惊险动作很重要，但主体分散，难以裁剪 | 保留原有2/3判断；依赖照常填。可不画，构图选低或无合理框，备注「相关主体分散」。 |

## 8. 提交前检查与双人规则

每题提交前只检查这几件事：

- 等级、阶段、类型、判断把握四项都填了。
- 2/3填了信息依赖；有框时填理由和构图把握；无框时说明没有合理窗口。
- 每题最多一个框，框没有裁掉解释事件必需的内容。
- 不确定配低把握，并写清缺什么。没有因为配额、位置或裁剪困难改等级。

甲乙独立完成。可以讨论「规则是什么意思」，但不要讨论「这个视频第几秒该选几分」或交换截图。乙不要阅读甲的Smoke逐题修订报告。遇到分歧先各自记录，不需要互相改到一致。

每人当前剩240题，共8个30秒视频；甲另外保留已做的60题。按每题20–40秒估算，新增工作约每人1.5–3小时，含看视频和短休息；这是排班估算，前30题后可按实际速度调整。宁可休息，不要批量复制答案赶进度。

项目分开保存结果；当前未配置不同账号的访问权限隔离，执行上只进入自己的项目，不查看对方结果。完成后告诉负责人，由负责人导出和比较，不自行合并或平均框。

## 9. 给研究负责人的版本说明

V1.3修正了旧标准把逐帧事件价值与短片选帧配额混在一起的问题：取消「少量帧」「重复帧应降级」「一个窗口通常只有少量3」等要求；相邻帧按自身时刻价值判断。明确一帧一个完整窗口，保留旧字段及四种框标签以兼容历史结果。

已有60份Smoke来自V1.2及用户修订，保留原版本、时间和导出快照，不自动写成V1.3重标。双人6个重叠源中，4个为双方新标，作为同版本一致性主分析；2个Smoke源含甲的旧协议历史，单独报告敏感性，不混称6源均同协议。

本批是公开视频机制诊断：等级不是比赛官方二值标签；30秒窗口不代表整片；自报信息依赖不证明视觉模型的能力上限。自由比例框没有指定目标宽高比，不是官方构图真值，不用于直接拟合比赛裁剪坐标。分析须保留每人结果、不确定与分歧，按原视频源统计；不能用这些标签声称官方涨分。
