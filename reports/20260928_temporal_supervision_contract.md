# 时间监督契约 v1（P3）

实现：`aic/temporal_contract.py`。核查：`scripts/temporal_contract_check.py`，结果在 `artifacts/TEMPORAL_CONTRACT_V1/metrics.json`。没有训练，也没有改变任何提交包的选帧。

## 对齐约定（修复 +0.99 s 偏移）

- 锚点分数描述的是锚点时刻本身（16 帧片段以锚点为中心）。
- 2 s 标签片段 k 覆盖 [2k, 2k+2)，用片段中心 2k+1 表示。
- 训练目标取片段中心的线性插值，在锚点时刻求值；取代旧的 `floor(t/2)` 查表。
- 推理仍用 `expand_scores` 在帧 PTS 上插值。这样训练和推理用的是同一个约定。

核查结果（native QVH，120 个视频）：

| 项 | 旧约定 | 契约 v1 |
|---|---|---|
| 锚点到其目标片段中心的平均偏移 | +0.990 s（系统性，全部同号） | 插值无系统偏移；最近中心的平均距离为 0.99 s，这是 2 s 分辨率本身的限制，正负对称 |
| 两者都监督时目标的绝对差 | — | 均值 .029，p90 .083 |
| 被监督锚点比例 | .302 | .280（跨越未标注边界的锚点不再监督） |

区分两件事：2 s 片段的分辨率限制仍然存在，这是数据本身的粒度；系统性 +1 s 映射错误已消除。

## 标签状态

| 状态 | 使用方式 | native QVH 实际数量（train / dev） |
|---|---|---|
| POS：可靠高光（人工 ≥ .75） | 保留监督 | 1,574 / 359 |
| NEG：可靠非高光 | 删除监督，需要人工或任务定义依据 | 0 / 0。QVH 只对与 query 相关的片段打分，没有通用负例 |
| QUERY_IRRELEVANT：与查询不相关 | 只对该查询成立，通用高光任务中 mask | 并入 IGNORE |
| UNLABELLED：完全未标注 | mask，不填 0 | 5,599 / 1,433 |
| TEACHER：教师推断 | 单独的弱标签通道，审计后才使用 | 未启用 |

结论：

- native QVH 只能提供"正例 vs 未知"，不能提供可靠负例。
- 用它训练二分类，要么全选（V0），要么把未知当负（E1 失败）。
- 下一步需要带可靠负例的来源，候选是 TVSum/SumMe 的全时间线人工分数（已在服务器，需先核对与 2 s 片段的对齐）或 MR.HiSum 回看热度（弱监督）。
- 在此之前，时间路线继续全选。
