# AIC 轻量视觉路线：研究裁决

日期：2026-10-19。仓库锁定：[`3b28ffc6bf61f0799d91c9ecf6113e83a98223fc`](https://github.com/lujunlin-cn/AIC/commit/3b28ffc6bf61f0799d91c9ecf6113e83a98223fc)。

## 决策

**该路线值得做一次有明确停止条件的验证，但“轻量视觉特征可以突破 40 分”仍没有足够证据。** 当前应主攻原生构图监督下的主体重要性与窗口决策；时间上保留轻量语义控制，避免把高光直接等同于显著性或大运动。

单一主线：**冻结时间选择，复现强空间基线，在相同候选、相同头部容量下，验证轻量主体信息对人工原生框的独立增量。** 主线首先是 H1 空间诊断。约 100M 部署随后以 R91 类轻量时间链接入，需要重新验证，不能把固定 R54 的历史输出直接称为 100M 系统。

唯一备选：**目标域选片监督下，静态小编码器加 shot 条件结构和相机补偿运动状态的时间残差。** 当 H1 在充分功效下低于实际收益门槛、当前候选空间已无足够余量，或空间资产无法在既定资源内恢复时，依次启动 H2、H3。它不是立即微调另一个大视频模型。

以下回答本任务要求的八个决策问题。

## 1. 100M 模型取得 40 分的传闻，支持到什么程度？

**本次未找到可核验的同赛段公开方案、完整参数账本和对应官方结果，因此传闻仍未证实。** 这不等于证明方案不存在。[R1][R2]

| 需要核实的内容 | 本轮证据 |
|---|---|
| 完整系统约 100M | 未找到传闻对象的可重跑系统；无法确定是否只统计训练头 |
| 冻结 backbone / 预提取特征 | 传闻对象未知；冻结和预提取不能免计测试推理依赖 |
| 大教师或多个辅助模型 | 传闻对象未知；训练教师与测试推理教师须分开 |
| 是否包含空间构图 | 未知；仅时间模型的 100M 不能代表联合系统 |
| 同赛段、同评价公式的约 40 分 | 未找到模型身份与成绩的公开对应关系 |
| 当前 AIC 自有小模型证据 | R91 声明98,584,754参数，未上传、无官方成绩；算术成立，完整部署谱系尚未闭环 |

R91 的参数分解为：ResNet18 11,176,512；时间线性头513；V9视觉85,843,200；空间头1,511,425；YuNet导出学习初始化器53,104。它复制已有全帧空间缓存，尚未证明这些缓存可由所声明权重端到端重算。原始 B3 权重身份也不能与 V9 替代链混用。[R3][R4]

R85 榜单快照说明存在达到或超过40的成绩，却不能识别其模型、标签或依赖。也不能因为 HL-CLIP/QVHighlights 有约42的 mAP，或 MS-DETR 有40.45的 mAP，就与 AIC 40分建立对应。[R2][P1][P2]

假如一个完整约100M系统确实达到40，较合理的条件解释包括：预训练视觉语义足够、空间框更贴近标注、时间预算与边界决策更匹配、目标域监督更好，或多个小模块形成互补。现有证据不能在这些解释中选出唯一原因，更不能推出“小模型完全没有语义”。

## 2. 复杂视频语义推理是必要条件吗？

**没有证据证明复杂语言式视频推理是当前任务的必要条件；同样没有证据证明语义可以完全移除。**

官方自动评分只读取精确帧号和构图框。对视频 i，非双空时：

\[
F_i=\frac{2\sum_{t\in S_i\cap G_i}\operatorname{IoU}(B_{it},G_{it})}{|S_i|+|G_i|},
\qquad Score=100\operatorname{mean}_iF_i.
\]

双空为1，单空为0；不同帧号没有容忍带。评分公式本身没有要求模型执行语言推理，也没有给平滑、事件描述或镜头去冗余单独加分。[O1][O2]

R26 的等预算中心时间策略优于当前 AHA；R43 的 InternVideo2 事件完成度也未赢过简单时间控制。这些结果削弱了“更复杂通用语义就会更高分”的假设，但只约束对应的输入、读出和监督。[R1]

另一方面，ImageNet、DINO、视频动作预训练和蒸馏都能把类别、姿态、对象关系或事件线索压入小网络。U²-Netp 的显著前景、UNISAL/TinyHD 的注视分布、检测器的对象框也不是纯粹像素强度规则。无语言输入、少参数和无语义并非同义词。[P3][P4][P5]

因此本研究保留 ResNet18 静态语义控制。只要新增低维特征无法胜过同数据、同预算下的该控制，就不能声称它们已替代语义。R42 的标注分歧和部分样本对声音/上下文的依赖，也说明孤立帧代理可能丢失必要信息；这仍是公开诊断，不是官方标签规律。[R5]

## 3. 哪三个低成本特征最值得优先测试？

| 优先级 | 特征 | 独立信息是什么 | 第一判别 |
|---|---|---|---|
| 1 | **主体范围与候选窗口关系**：前景重心、面积、覆盖、边缘截断、多峰间距 | 将“看见前景”转为“合法窗口保留了哪些主体与上下文” | 固定时间/候选，人工原生IoU；胜强基线并胜同容量无主体头 |
| 2 | **shot 条件位置与局部新颖性**：shot内相位、长度、距切点距离、局部重复 | 区分全片位置先验与局部内容结构 | 固定K/框，在静态语义控制之外检验observed selection capture |
| 3 | **相机补偿残差的前后状态**：局部运动面积、方向熵、速度统计变化、峰后停留 | 区分摇镜/转场与主体变化，区分瞬时峰和持续阶段 | raw/global/residual/phase对照；控制FPS、切点、类别和补偿可靠性 |

第1项证据最直接：历史上空间框能在固定时间条件下改变官方分数，且公开数据存在真实 crop GT。第2/3项机制合理，但 R89/R90 尚未给出独立时间增量；它们需要新的干净对照。[R1][R6][R7]

不优先单独测试“光流越大越高光”“注意力熵越低越高光”或“轨迹越平滑越好”。这些标量混有相机运动、字幕、中心偏置和镜头风格，且不直接对应公式中的联合效用。

## 4. 哪些公开模型最值得迁移？

登记表覆盖28个条目，每个提供19项统一字段。第一批只保留五个优先候选，按所需信息启用，并非同时常驻全部模型。

| 候选 | 角色 | 参数/核验 | 决策 |
|---|---|---|---|
| U²-Netp | 冻结静态前景 | 1,131,181；已取得权重并核元数据，无forward | H1首选通路；外部权重许可需按实际分发条件确认 |
| DIS + LK/RANSAC | 稠密运动及相机补偿 | 无学习权重；目标管线未测速 | H3首选控制，先证明信号再考虑深度流 |
| PySceneDetect | shot和转场混杂控制 | 无学习权重，目标版本未运行 | H2低成本起点；错误明确再用TransNetV2 |
| ResNet18 | 轻量静态语义锚点 | headless11,176,512；现有R91设计可复用 | 第一轮冻结，不因负结果马上全参微调 |
| UNISAL 固定source的视频路径 | 真实邻帧与重复当前帧对照 | checkpoint3,715,640；已取得，无forward | 固定域BN/prior、预处理和crop映射；image/video跨域对比不作纯时序归因 |

上述模型的原论文、官方源码、下载状态、许可证和成本条件见 `open_models_registry.md`。5份实际取得的空间权重都有字节数和 SHA256；下载与参数元数据核验均不等于真实推理验证。

TinyHD-M rc4 的515,281参数很有吸引力，但无明确LICENSE、采样与真实吞吐尚待核验。YuNet已在现存链内，应复用；RTMDet-tiny只在缺少人体/器械范围时增加。DINOv2-S作为更强空间token控制，RAFT-small作为流质量控制，均有清晰触发条件。[P3][P4][P5][P6]

不选 BASNet、IS-Net 或 DiffSal 作为第一项新模型，是因为目前缺少证据表明更精确边界、更高分辨率或更重注视预测就是构图瓶颈。2026 LIVE-YT 研究也表明，人工窗口决策与普通显著性并不等价；其全高、原生高度和平滑GT结果必须分别看待。[P7]

## 5. 已有失败说明了什么，又没有排除什么？

| 证据 | 可以关闭或降级的解释 | 仍应保留的可能性 |
|---|---|---|
| R29 两标量校准无稳定增量 | 当前标量再校准没有足够证据 | 表征层目标适配、中间空间token |
| R30 高维动态特征源外失败 | 当前高维差分读出泛化不足 | 低维补偿残差、正确短时采样、目标监督 |
| R43=34.95 | 当前事件完成度读出弱于简单控制 | 非语言阶段、域匹配的高光偏好 |
| R69=24.95，轨迹却更平滑 | 平滑不能作评分替代目标 | 有身份/IoU约束、切点重置的轨迹决策 |
| R82=36.20 | 当前公开utility代理不保证官方排序收益 | 正确监督与联合条件下的utility估计 |
| R83 8槽、两种7/8连续窗口退化 | 该受限动作空间无增量 | 更密集的事件边界和不同集合空间 |
| R86最新34.88 | A1raw点源+H1映射组合失败 | B3点源上的映射效应尚未干净识别；R88未上传 |
| R87 NaN已修复 | 运行时阻塞不再是关闭适配的理由 | 连续标签AP与有效源聚合仍需修正 |
| R89约+.004104对中心 | 有小幅开发信号，未超过强控制 | 旧Confirm已暴露；no_motion仍含运动，不能否定运动 |
| R90 bank约−.01002对静态 | 当前32D组合不能替代静态语义 | 语义差分混尺度；正常补偿流与阶段尚未被该实验否定 |
| R91约98.585M、未上传 | 小模型候选已形成 | 没有40分证据，空间缓存依赖仍未闭环 |

数字来自固定提交的仓库记录，本轮未复跑真实数据或独立核验平台上传字节。[R1][R3][R6][R7][R8]

本轮还发现本地 evaluator 保留旧 `model_size_mb` 乘数。纯合成完美预测配200MB字段得到95，只填现行参数字段可能被旧合同拒绝。**这是本地代码过时的证据，不是当前平台评分行为的证据。** 在修复前，不应据本地“总分”判断细小增量。[R9]

## 6. 最值得执行的第一项实验是什么？

**第一项新学习实验是 H1：固定时间，U²-Netp主体特征加小候选头，对可复现强空间基线做原生IoU验证。** 它之前有一个必要的低成本工程步骤：修复评分/标签/特征合同，并把 B0 的权重与空间输出谱系闭环。

H1 只有一个主要新候选。比较中心框、强基线B0、显著重心、显著性+关联轨迹作为控制；新头另有同容量无主体输入的必要消融。将B0原始框纳入固定候选，避免“统一网格”削弱基线。轨迹输出保持在候选集合内，候选oracle只在开发源用于选设计。

主要指标为每源等权的原生框IoU，保留多标注者和两种比例。建议最小实际收益 δ=.010；同时要求新候选胜B0、且主体通路胜同容量无主体消融。旧LIVE/RetargetVid只能用于开发，最后确认必须来自历史未消费的新源。

功效可能是实际瓶颈。若配对差异标准差为.04，三假设保守门槛下检出.01增量约需168个独立源；标准差.08则约671源。这是拒绝零增量的80%检出功效近似，不是完整晋级规则的80%通过率。无法取得足够新源时，应承认确认能力受限，不把几千个同源帧伪装成大样本。

硬件方面，先用CPU做合同、帧差与统计，冻结前景可在实际可用的单GPU上提取；本轮只检测到当前容器有CPU与ffmpeg，未检测到可用GPU/NPU管理工具，历史机器在线状态未核验。具体时间、显存都要由固定1,000帧profile后外推。

## 7. 什么结果会使我们放弃当前假设？

以下是预先定义的停止理由，而非事后解释：

1. **当前候选族没有足够余量。** 开发源上的候选oracle−B0上界低于δ，则停止这个候选头方向；如果最终窗口可离开该候选集合，不能用它否定另一种连续窗口模型。
2. **充分功效下新增主体通路不支持实际收益。** 源级98.333%CI上界低于δ，或同容量无主体消融未被击败，则不能按主体机制晋级。
3. **收益只是中心/位置/拍摄类别的代理。** 匹配控制后消失，或主要类别出现超门槛退化，则不作通用部署。
4. **工程成本或复现不成立。** 完整参数、缓存上游、权重身份、目标算子或端到端成本未通过，判工程No-Go；这不否定信息通路本身。
5. **时间备选仍不能越过静态控制。** H2/H3在统一K、框、PTS和正确运动实现下，独立确认不支持δ=.005，则停止相同bank加复杂头的升级。

每项都报告常规95%CI；晋级另用三假设的98.333%CI，避免反复尝试只报告一个阳性。CI很宽、或正CI尚不能达到实际门槛时，结论是证据不足。一次小样本阴性不能成为“所有低维视觉都无效”的结论。

H1通过只支持空间模块继续；完整100M目标还需要小时间链保持有效排序并通过联合回归。当前最好已报告36.43，到40差3.57个官方分，即平均F需增加.0357；公开crop IoU与GIF capture的变化都不能直接兑换这个差距。

## 8. 如果 H1/H2/H3 都失败，转向什么不同路径？

**转向新的监督与上下文信息，而不是把相同特征继续拼大。** 优先建立一批合法公开视频上的、完整上下文的联合时间—空间人工标注。

先做24–40个新源的协议试验，由至少两名独立标注者观看完整片段，标注应保留的事件区间、原始帧ID、对应画幅的构图框、主体及不确定性。记录选择是否依赖声音、字幕、动作前因或结果。允许“整段无明确高光”，但必须经过全视频审阅；不能由某个GIF未选择推导为空。

这一步不是为官方隐藏测试补标签，而是创建可审查的公开监督。先检验标注者能否在同一明确政策下达成稳定判断，再扩大训练规模。对R42重复性差的类别，优先修订协议和上下文呈现，不直接硬化等级标签。

如果一致标签确实依赖音频/字幕或更长的前后事件上下文，再选择相应的小型编码器或训练期教师。教师只在公开训练源产生可追踪、可抽查的辅助目标；新学生在新源上验证，不能以教师输出冒充人工联合GT。

这条路线能区分四种不同失败：观测里没有所需信息；已有信息不可被当前表示读出；监督偏好与AIC不同；输出集合或坐标合同错误。前三项轻量实验应帮助定位到其中之一，不能都简化成“模型不行”。

## 最终资源分配建议

立即开展合同、资产与H1开发oracle核验；只在这些通过后支付新确认标注和单一轻量头成本。首选完整轻量架构为 **ResNet18静态语义 + U²-Netp主体统计 + 通过验证的低维shot/motion + 小时序/空间读出**，一个明确层结构的参数算例约12.38M。但部署初期优先保留已验证较强的V9空间链，约99.79M的扩展预算仍以完整依赖可复现为前提，不能由更小的算例直接推断它更好。

本轮完成的是研究、资产/代码审计和实验设计。实际执行包括确定性合成检查、部分权重下载及静态/元数据参数核验；没有开展目标视频训练、NPU测速或官方提交。五份文件中的所有未测性能、计划阈值和工程接口均按各自状态标明。
