# 路线 03：Qwen3-VL-32B 教师的主体点、语义清理与离线蒸馏

整理日期：2026-11-07。总入口：[index.md](index.md)。**32B 完整系统不满足当前总推理参数≤9B；这里的高分是历史研究证据，今后可讨论离线 teacher 用途。**

## 主路线

`视频关键帧 → Qwen3-VL-32B 主体点/区域/事件判断 → 最大合法裁剪窗 → 点位传播/插值 → 时间语义清理 → JSONL`。

最初问题是人脸检测无法覆盖非人主体、多主体和动作观看价值。语义 teacher 把“脸在哪里”替换为“观看主体在哪里”，随后扩展到观察密度、时间剔除、构图校准和视觉复核。

## 复赛状态与重要勘误

项目记录了32B教师复赛 **34.84**，但这不是当前合规部署候选。早期“除以k_size估计raw=38.71–48.39”“教师被规模惩罚压制”等解释已失去当前规则依据；保留原回分，不进行事后换算。

“teacher区域更精细所以crop更好”曾被实际负结果推翻。teacher点与学生候选头的比较也出现过GT列号用枚举索引而非真实帧号的bug；V8修复后，重合帧口径的师生互补Δ为+0.0263，而不是旧+0.0105。链级fallback口径与双方均成功的重合帧口径必须分别说明。

32B输出可以作为合规公共训练数据上的离线蒸馏信号，但官方测试上的teacher推理结果、官方回分及其反推信息不能转为训练或伪标签。

## 当前判断与讨论题

历史上最可靠的大增益来自语义主体点和粗时间清理；更精细的区域、学习映射、视觉复核没有稳定延续收益。它提示未来蒸馏应明确迁移哪一种能力，而不是简单混合所有teacher数值。

1. 应蒸馏主体语义、候选相对偏好、事件边界还是无效片段清理？哪些能力已有独立学生证据？
2. 能否用≤9B模型或离线监督保留NOFACE/TEMP机制，同时避免teacher局部标注偏差？
3. 若重做KD，应怎样控制公共人工GT、teacher增量和几何增强的独立贡献？
