# R15b 监督信号与官方域诊断记录

> 2026-10-14 · 三路并行研究（评分口径反推 / 外部方法调研 / 4B 基座考古）+ 一次本地实测反解
> 目的：搞清 **L ≈ 1.05**（排序提升倍数，排序器只比随机好 5%）的成因，以及在**无官方 GT** 前提下能否补救。
> 结论摘要：**根因是切段器把高光窗放在段中心，训练标签本身是一条钟形曲线；部署到整轴推理时该先验消失，内容信号≈0。** 这是我们自己的数据构造缺陷，不是官方域的错，且可修。

## 1. 背景：L 是什么，为什么它是我们真正的瓶颈

从**已知官方分 + 实测帧数**反解（`vp_ref/solve_L.py`，样本 `/tmp/run7_pkg/` 五个落盘包）：

记 `N`=总帧数、`d`=GT 占比、`p`=预测帧占比、`rho(p)`=召回、`Rbar`=匹配帧平均 IoU。两包共享空间框 ⇒ `Rbar` 相消：

```
rho = (F_keep/F_full)·(p+d)/(1+d) ,   L = rho/p
```

| 包 | 官方分 | p_mean | L (d=0.21) | rho |
|---|---|---|---|---|
| v8b3（全帧） | 34.75 | 1.000 | 1.000 | 1.000 |
| v8t | 34.88 | 0.7745 | 1.055 | 0.817 |
| pkgA | 35.17 | 0.8522 | 1.043 | 0.888 |
| **pkgB（当前最高）** | **35.52** | 0.8547 | **1.052** | 0.899 |

**L ≈ 1.04–1.11，跨 d∈[0.15,0.6] 全域稳健 > 1。** 这就是"114M 与 4B 同分"的机制：参数量差 35 倍，两个模型都被压在同一条 L≈1.05 上。

⚠️ 一次被纠正的误判：外部研究初判 "L≈0.95<1、排序不如随机"，源于误用 k_size 分支。**复赛已取消 k_size 惩罚**，按规则口径重算 L>1 成立。权威公式是赛事规则 `01_赛事规则与评分标准.md:147-158`，不是同事给的 `eval_official.py`（后者非官方，两处冲突：空段 F_i=0 vs 规则=1；重复帧 dict 折叠 vs 规则 `:131` 计入 N_pred 不得分）。核心代数式 `F1=2·S_IoU/(N_pred+N_gt)` 两边一致。

## 2. 根因：切段器把高光窗放在段中心 [事实]

`scripts/r13_phd2_sft_pool.py:81-83`：

```python
T = clip(choice(d426), 4, 60)
c = (t0 + t1) / 2      # ← 高光窗中心
s0 = max(0, c - T/2)   # ← 以窗为中心切段
```

实测后果（12 帧 v2 池）：

| 指标 | 读数 |
|---|---|
| `\|c−0.5\|<0.05` 的段占比 | **93.5%** |
| 标签正质量质心与窗中心平均距离 | **0.001 段长** |
| 标签位置剖面 | 完美钟形 `0.16 .22 .30 .43 .64 .95 .94 .64 .42 .28 .21 .15` |

**标签本身就是一条钟形曲线。**

## 3. 位置先验吃掉几乎全部标签信息 [事实]

协议照抄 `vp_ref/arc_check2.py`（arc 用训练集拟合，指标=段内 spearman 均值）：

| 预测器（不看任何画面） | holdout spearman |
|---|---|
| **固定位置曲线** | **+0.7500** |
| 固定线性斜坡 i/(T−1) | +0.5936 |
| 作弊 oracle（位置+段级聚合+自身 gif_soft） | **+0.8777** |
| **我们最好的 ckpt_030** | **0.539** |

12 帧 v2 侧：`spearman(gif_hard_段, 固定12点钟形)=0.697`（1696 条非退化段）——**70% 的标签序信息由一条无内容曲线复现**。

**标签信息上限 0.878，位置先验占 0.750，留给"内容"仅 0.128 个 spearman 点。** 这就是 L≈1.05 的算术来源：整轴推理时位置先验不存在，可迁移净内容信号≈0。

## 4. 第二条：teacher 与 gif 近似正交 [事实]

| 指标 | 读数 |
|---|---|
| teacher vs gif_soft 段内 AUC | **0.5291**（随机水平） |
| 段 AUC<0.5 的比例 | 51.9% |
| 逐段 spearman 均值 / 中位 | 0.037 / −0.082 |

`_target = 0.6·teacher + 0.4·gif_soft` 是**两个近似随机源的加权和**。验收门 `spearman(teacher,gif)<0 → 丢段` 把两源的**分歧当噪声删段**（筛掉的恰是信息量最高的段），而非修标签。

8 帧 v1 池：48.2% 全零段，96% 的非退化段只有 1 个正帧 → 标签退化成"哪个帧是峰"（1 bit）。

## 5. 为什么残差化单独做会失败 [事实]

`spearman(gif_hard − arc, _target − arc) = 0.0254`（8 帧）。**残差里几乎没有可用信号**——因为 arc 已经吃掉了标签的绝大部分方差。

修法必须是"**把钟形从标签侧挪到输入侧**"：段几何中心作为显式输入特征，标签只留残差；或者更彻底——**均匀切段，让位置先验在构造上失效**。

## 6. 本地门为何失效：三个机制 [事实+推断]

"三次反向指示"的真实机制（不是指标算错，是指标没功效）：

**机制 A——段内 spearman 对逐段单调变换完全不变**（数学恒等式）。构造性证明：合成 8 段×12 帧，段内 spearman `raw = 逐段 z-score = 逐段 rank = 0.673077`（一位不差），但官方式 F1@keep=0.855 `raw=0.3517 vs 逐段z=0.3103`（差 11.8% ≈ 4.2 官方分）。**本地指标完全相同，官方分差 4 分。** 决定 F1 的是"段间可比性"（跨段分数刻度），spearman 家族对它的分辨率是 0。

**机制 B——有效样本量 16 段**。Fisher-z：n=12点/段、M=16段 ⇒ SE=0.0833。四次本地对比的 t 值：VPB vs ckpt_030 = 0.38、fused vs gif = 0.69、rank vs binned10 = 0.15、rank vs bce = 0.30，**全部不显著**。

**机制 C——双重采样**。同一 holdout 既做早停（patience=20/200 轮取 max）又做汇报 = 16 样本噪声在 200 epoch 上取最大值。指标实际在奖励"背 arcline"。

## 7. 本地门不可构造 [事实，五包证伪]

| 代理 | 与官方分的 spearman | LOO-R² |
|---|---|---|
| keep 比例 | −0.205 | −6.53 |
| LOO 共识 recall | −0.205 | −6.01 |
| LOO 共识 precision | −0.205 | −0.058 |

四条独立否证：
1. 交叉验证全负，最好代理 MAE 0.293 > 信号跨度 0.77 的 38%；
2. "包间一致性"族在数学上塌缩到 keep 比例（r=0.999868）——**等于换个写法测 keep**；
3. v8b3 ⊇ 其余四包 ⇒ LOO recall 恒=1.0，被排到代理第 1 名而官方第 5 名；
4. 距离→分差严格非单调（pkgB–pkgC 距离 0.618 > pkgA–pkgB 0.555，但官方分**相等**）。

**结构性论证**：0.35 分差距对应 14.3% 的帧翻转 ⇒ GT 质量里绝大部分是随机成分，**信噪比≈2.8%**。用无 GT 统计量测 3% 信噪比的信号，不可能。

**结论：诚实地说，无官方 GT 前提下本地门不可构造。** 计划书禁令 #14 应升级为绝对禁令。

## 9. 无 GT 条件下的路线判决

### 9.1 共识伪标签——不可行 [文献证据+推断]

共识/真值推断（Dawid-Skene 系）的方差缩减**依赖标注者在给定真值下条件独立**。我们的信号源（teacher、池 v4、27B、位置先验）全部源自同一份 `gif_hard`，条件相关性≈1。共识只会平均共享偏差，而共享偏差的主要成分就是弧线先验（对任意 target spearman 0.75）。**不建议投入 >2 人日。**

唯一可保留构件：**位置先验残差化**（把钟形显式加性项，不污染 target）。但失败判据严苛——残差与外部标签 spearman <0.05 即判死（当前实测 0.0254，**已在悬崖边**）。

### 9.2 TimeLens 的 10 万自动标注不可迁移 [文献证据]

TimeLens（CVPR 2026, arXiv 2512.14698）的视频域就是 Charades-STA / ActivityNet / QVHighlights 三个**已有标注基准**，LLM 只重写 query 与 segment。它成立的前提是**源视频域与目标域同分布**。我们恰好相反：R12 审计显示 426 集与训练数据仅 1/426 通过指纹验证。

同理官方 baseline TempSamp-R1（NeurIPS 2025）的训练数据也是 QV 域（已判死）——**它不是新监督源，是同一批外部标注的 RL 蒸馏**。但其 RLVR 配方（thinking-free、G−1 on-policy + 1 GT off-policy 锚定）可迁移。

### 9.3 测试时适应 / 自训练——不可行 [推断]

熵最小化需要二分类后验，而 top-k 正是待学量（循环论证）；自训练会**加强**模型自己的弧线先验。

### 9.4 唯一可辨识的路径：反解密度谱 + 分配 keep [推导]

由 `F_i(q)=2·mu_i·d_i·rho(q)/(q+d_i)` 求极值，**框质量 `mu_i` 整项约掉**：

```
q*_i = argmax_q  d_i·rho(q)/(q+d_i)
```

**最优 keep 只取决于 GT 密度谱 `d_i` 和召回形状 `rho(q)`，完全不由排序能力决定。** 这把问题从"排序"（L≈1.05，35倍参数无改善，死路）转成"分配"（两个低维标量，可反解）。

- **空提交**（规则 `:163`：两者皆 0→F_i=1）给出 `F = 空GT视频占比`，**无假设的免费官方域读数**。
- **每次提交只返回 1 个标量**：426 个 `(u_i,g_i)` 未知量，逐视频反解需 ≥852 次提交，**物理不可能**。可恢复的只有我们**故意设计成粗聚合**的少数对比量。
- **最优 q 只依赖密度谱与召回形状**，而这两者可由少量聚合探针反解。

## 10. 方法学：官方域探针的可辨识性 [推导]

### 10.1 p 扫描（推荐先发）
`F(0.95)` 预测 36.04–36.47（对 d∈[0.15,0.30] 稳健），+0.5~+0.9，信噪比>5000。**单名额。**

### 10.2 等长位置探针（3 名额，解锁标定）
把每视频帧按位置切成 K 个**等长**类，第 j 包只保留第 j 类。所有分母相同（N_i/K），**包间差分干净读出各位置类的 GT 质量**。

- `sum_j Score_j = f(K)·Phi(1)`，`f(g)=(1+g)/(1/K+g)` 单调递减 → 该和唯一钉住 g_i 分布的一个泛函，是 d 的强单射。
- K=3, d=0.21：`∂(Σ_j Score_j)/∂d ≈ -78.5 分/单位 d`；报分分辨率 0.005 ⇒ **d 解到 ±1e-4**。
- 额外白拿：**官方加权的头/中/尾 GT 质量剖面**（把 §8 的间接推断变成直接测量）。
- **不可辨识**：426 个 `(u_i,g_i)` 永远不可辨识；只恢复 d 的一个泛函 + 位置剖面 K−1 个对比。

## 11. 反向证据（不能全盘接受"冻结特征够用"）

- **E2E-TAD（CVPR 2022）**：mAP 口径下**端到端 > 冻结特征**（THUMOS14 +9.4~+11.2 mAP）。"冻结特征够用"只在 F1 的低分辨率区成立。
- **指标无分辨率**：同一批模型，TVSum 上 mAP 8M vs 7B 差 20 点（MINI-Net 0.7324 vs Aha 0.916），F1 只差 0–3 分。
- **小模型确实能赢**：WANet 5.25M 打爆 SUM-GAN 295.86M；DR-DSN 2.63M / FullTransNet 3.538M。**但 7B VLM 直接崩**：LLMVS（CVPR 2025）LLaVA-7B 零样本 TVSum τ=0.051，低于人类一致性 0.177。
- **"100M 拿 40"无可验证案例**。全帧常数预测得分 = `2·0.62·p/(1+p)`：p=0.39→34.8，**p=0.476→恰好 40.0**。最可能是常数预测器 + 不同 GT 密度/口径（Otani: SumMe max vs TVSum avg，同模型差 21 分）。
