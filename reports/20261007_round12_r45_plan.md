## 1. 复赛得分全景（全部平台实测，k_size 未经换算）

| 包 | 配置 | 平台分 |
|---|---|---|
| LFM_V8_B3_TEMPORAL | B3 + TCN 掩码 keep0.80 | **34.88** |
| LFM_QWEN32B | 32B 教师+YuNet | 34.84 |
| LFM_V8_B3_SEMIFINAL | B3 全模型 | 34.75 |
| LFM_V9_B3_VISIONONLY | B3 头 vision-only | 34.73 |
| LFM_V9_VISIONONLY | A1 KD vision-only | 34.61 |
| V7 | S 头 | 33.82 |
| LFM_B0_SEMIFINAL | YuNet 人脸跟随 | 31.58 |

三个决定性事实：
1. **教师与学生同分**（34.84 vs 34.75）——更大教师/更强蒸馏不是路，复赛域需要的信息教师链里没有。
2. **换头/换部署全部 ±0.1**（7 个学习型方案挤 33.8–34.9），唯一结构性例外 B0=31.58。
3. **GPT-6-PRO 几何口径**（159/426 无 slide、m_xy≈0.62、p≈0.33）：40 分需 temporal F1≈0.58，**45 分需 ≈0.66**——在 Oracle A（现有排序+逐视频最优 keep=0.7804，本地口径）之内，数学可达。

瓶颈机制（平台侧反推）：keep0.80 掩码只 +0.13 平台分 ⇒ 掩码排序质量仅比随机好 **~7%**（完美 keep0.8 应 +17%）。45 分需要把排序质量推到「比随机好 38%」量级或解锁逐视频 keep 决策。

## 3. R12 策略转向

**从「本地迭代→攒大包」转为「平台差分→归因」。**
- 名额纪律更新（用户 10-07 指令）：每天 5 名额按可忽略执行；每包**单变量、机制命名**；同一机制至少 2 个变体（seed/强度）才可归因（平台噪声在 tied 头上实测 ±0.88）。
- 本地模拟池（PHD2/QV/live）降级为「预检」（排序头能否训出来、管道是否健康），**不作为关闭依据**。
- 平台即标注器：每个包的官方回分 = 官方域的一次免费测量，差分直接归因到机制。

## 4. 阶段与预算

### 阶段 0：本地准备（Day-1，CPU，~1 天）
- **P0-a 复赛域画像池**：汇总官方 426 集已知统计（p50 14.1s、66% 横/29% 竖、159 无 slide、23% 无音轨、回执帧量）→ 对本地池重加权，构建「域自适应预检池 v1」。只做预检，不做门。
- **P0-b PHD² user-vote 标签重建**：V10 census 实锤 upstream `training.csv` 有 user 字段而聚合 train.json 丢弃；83.3% 单用户、user-pair 分歧 0.127——user-level 聚合从未测过。重建 user-vote 标签（置信度加权），零下载成本。

### 阶段 1：平台快扫（第 1–2 周，~12 个名额）
每包 = 一个机制 × 2 变体；回分后按差分归因。

| 包 | 机制（单变量） | 假设 |
|---|---|---|
| R12-QV | **QV saliency 主监督** TCN keep 头（22 标注者 0–4 连续分，7,100 视频在盘全量管线现成） | 高质量人工密集监督直接提升排序质量（当前掩码仅 +7%） |
| R12-KEEP | 同 QV 头，**keep 0.80→0.60** | keep 深度 × 排序质量的交互；本地扫描判据已失效，平台直接测 |
| R12-UV | **PHD² user-vote 标签**重训 B3 时间头（vs GIF-union 单变量） | 标签聚合方式是 83% 单用户池的未测自由度 |
| R12-VMAE | **VideoMAEv2 ViT-B 端到端**时间头（M01 NPU 桥，86M，k_size 0.9 档内） | SigLIP pooled 是表示墙；时空原生特征第一次端到端训排序 |

### 阶段 2：按平台差分收敛（第 3 周起）
- 任一监督源平台正 → 全量扩训 + 校准 + **自适应 keep 解锁**（校准前提是概率型监督；Oracle A 的 +0.116 决策层空间在此兑现）。
- QV 正 → QV+PHD² 双监督联合、置信度加权；QV 负且 UV 正 → 深挖 PHD² 标注形态。
- S2c Light-ASD / S2b 跟踪连续性按 R11 计划继续（低成本支线，不占主预算）。

### 阶段 3：排序墙仍在时的升级路（预算外，需环境/用户裁定）
- **VLM 判别式蒸馏**：Qwen-VL 逐段 pairwise「哪段更精彩」→ 蒸馏 keep 头。教师 34.84 是「点位+YuNet 链」的分数，**32B 的判别能力从未被用于复赛域 keep 决策**。需 910B 或环境决策（重建/离线）。
- 音频事件端到端（BGM/笑声/掌声 → 高光先验，23% 无音轨回退）。

## 5. 止损与风险
- 平台噪声 ±0.88：每个机制 2 变体起步，单包不作结论。
- QV query 偏置风险真实存在（saliency 与 query 无关部分才是目标，标签已按无 query 口径取 saliency_scores）。
- 域画像池只是预检：finding 3 的教训是任何本地判据都可能无平台效力——预检只拦「训不出来/管道坏」，不拦「本地没增益」。
- VMAE 若 NPU 训练稳定性差（Conv3d 桥 grad 已验 exact），回退 CPU 小规模 pilot + 官方回分。
