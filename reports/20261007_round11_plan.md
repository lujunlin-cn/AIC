## 2. 线路设计（四层 → 四条线）

### P-S 空间线（主攻，用户点名）

**S1 ★ 分数场时序约束解码审计（CPU ~2h，无 NPU）**
- 假设：B3 逐帧独立 argmax 存在时序抖动；标注均值 GT 下，时序一致性解码有正增量。
- 方法：冻结 B3 逐候选分数表（129 grid npz，910A 已有），Viterbi 解码 cost = −B3_score + λ·|c_t − c_{t−1}|，λ∈{0, 0.25, 0.5, 1, 2} 折内选；源级配对 vs B3 argmax；置换对照+locked-out 判定。
- 与 F7 的区别（预注册里写明）：测点是 B3 utility 分数场，非 B0 观测点；若仍 null，轨迹支路在「候选格框架」内关闭，只剩 S2 的候选源扩张。
- 晋级门：live_dev 与 locked-out 双池源级配对 delta ≥ +0.005 IoU 且 CI>0。
- 关闭线：best λ 增量 < +0.002 → S3 关闭，S2 转为唯一空间支路。

**S2 ★ 三源候选/身份审计（≤6 NPU-h + CPU 评估）**（v2：由单检测器扩为三源，对应截图第四层 identity/tracking/active-speaker 排队项 + R10 未测族 SPATIAL_IDENTITY）
- 假设：检测器/跟踪/active-speaker 提供 GT 未显式编码的「主体在哪、是否连续、是否在说话」；合法用法=新候选 ∪ 新先验 ∪ 新特征（F6 只禁止替换输出）。
- 三源：
  a. 检测：GroundingDINO（V100 用过，910A 算子覆盖未验证；备选 RT-DETR/YOLO-World；4h 止损）；
  b. 跟踪：帧间 IoU/ByteTrack 式 ID 连续（CPU，零依赖）——同时为 S3 轨迹提供主体连续性输入；
  c. active-speaker：Light-ASD（CVPR 2023，AVA 94.1%，实时，数 M 参数合规）——复用 R10 已提取的全池音频缓存，脸部轨迹 + 音频对位；PHD2 为创作者口播视频，「谁在说话裁谁」机制先验强，但池内 BGM+人声构成（R10 3.1：Cheering σ=0.0005）提示口播占比待测，先跑 32 源存在率审计再定投入。
- 步骤：① 各源 smoke→parity；② 100 dev 源逐帧提取；③ 三个免费读数：
  a. 新池 oracle（源框∪129 格点）− 旧池 oracle：候选天花板是否抬高；
  b. B3 分数与三源框一致率：是否只是 B3 已知信息；
  c. 三源做先验的条件重排 dev IoU。
- 门：a ≥ +0.02（否则 dense 候选无意义）；c ≥ +0.005 CI>0。
- 免费降级路径：NPU 检测器全不可用时，用 SigLIP 特征图做粗区域提案（弱，但零依赖）。

**S3 轨迹化裁剪训练臂（条件于 S1 过门；CPU 或 1 卡，≤4h）**
- 形式：候选=33 格点 shortlist（F3 已证 regret 0.0055 足够）；打分=B3×检测先验（若 S2 过）；解码=DP 时序约束（S1 的 λ）；可选再训一个带时序层的轻头（复用 910A TCN 训练链）。
- 门：live_dev + locked-out 双池 ≥ +0.01 IoU 且 CI>0（+0.375 分当量）。
- 失败预读：S1 过、S3 败 → 抖动收益是标注噪声而非信号，记录后整体关闭。

**S4 官方域分歧审计（任何空间包的前置硬门；CPU）**
- 动机：F8 三连败。方法：官方集跑 B3 vs 候选改动的逐帧分歧率；按 F12 分层（饱和 159 vs 可裁剪 267）；饱和集改动率必须低于可裁剪集且总量与本地 dev 相差 <2×；人工抽 20 源复核方向。
- 打包纪律：S4 不过不出包。每日 5 提交名额不消耗于未过 S4 的候选。

### P-O 观察线（第一层；v2 新增——GPT-6-PRO 自称最重视的一层）

**O1 ★ scout→verifier 双阶段 pilot（scout 层 CPU 免费；verifier 4 NPU-h）**
- 假设：8 锚点观察本身不含判别信息时，换 loss/backbone/RL 都无效（GPT-6-PRO 原话）；增加 observation 才是正道。
- scout 层（现成资产，零新提取）：R10 全池音频/ASR 产物重读——语义密度弱正读出（+0.002~0.006）重解释为「可疑区间定位器」；输出每源 top-k 可疑区间。
- verifier 层：对可疑区间加观察密度（更高帧率特征或 VLM 推理），新观察作为 slot 残差读出的新特征块（R10 同协议双门）。
- 门：可疑区间特征进残差读出 ≥ +0.005 CI>0（全池 M=984 MDE=0.0015 可判）；查询预算按 OBS025 先例记账（5,765 次可行）。
- 外部对应：ReAgent-V（NeurIPS，奖励驱动帧选择）、Deep Video Discovery（工具型 agentic 搜索）、自适应帧采样（见附录 B）——方向外部活跃，非孤例。

**O2 部署形态预审（CPU，O1 过门后）**
- 学生 ≤9B 内两阶段（scout=学生轻层，verifier=学生主体）vs 训练期 teacher 密集观察+学生稀疏蒸馏。合规红线：32B 不进推理依赖链。

**O3 RL 扫描动作（挂起）**
- GPT-6-PRO：「动作决定下一步看哪里」是 RL 的适配地。R8 E 臂的全信息精确策略梯度技术可复用到扫描动作空间（信息增益效用），条件于 O1 证明可疑区间定位有信号。注意：R8 E 臂 DECIDED_FAIL 是 36 候选效用上的结论，不构成对扫描动作空间的判决，但也不许当翻案依据。

### P-V 监督工程线（第二层；NPU 条件于 R10 释放）

**V0 ★ dense-view 前提探针（CPU/少量 NPU，≤2h）**（v2 新增）
- R8 §2.5 的 KD 移植前提：dense view 必须先在真标注 IoU 上胜 sparse view。此前提从未直接测过。密集原帧（native contract 已冻结，R5 §3）vs 8 锚点在同一头下的 IoU 差即答案；败则 KD 支路不启动，省 6 NPU-h。

**V1 32B teacher 事件结构 pilot（4–8 NPU-h，R10 结束后启动）**
- 形式：teacher 对 100–200 dev 源产出结构化 JSON {事件边界、主体、状态变化、高潮}（结构化输出约束，复用 V11 已验证的解析链）。
- 读数：事件特征进 q_s = b_s + h(X) 残差读出（R10 同协议、同双门）；高潮定位与时间 GT 对位。
- 门：残差 +0.005 CI>0（全池 M=984 时 MDE=0.0015，可判）→ 晋级 VLM_SFT 数据构造；否则第二层记负结果。
- 合规：32B 输出只作训练监督，禁止进最终推理依赖链（既有规则）。

**V2 counterfactual pair（CPU，条件于 V1 结构可用）**
- 同事件不同位置 pair → 偏好/对比损失，挂在 R8 VLM_SFT 臂上；先构造 1k pair 测判别力再扩。

### P-K 决策重构线（第三层；挂起）

- 触发条件（F13 + GPT-6-PRO 原话）：V1/O1 的事件结构能可靠判别「单高潮 vs 全段重要」（即输入信息变化成立）才重开；双门同 R10。未触发不动。
- 触发后按序试三类形式（GPT-6-PRO 原文）：①每视频保留帧数预测 ②连续区间输出 ③事件级密集原帧预算。
