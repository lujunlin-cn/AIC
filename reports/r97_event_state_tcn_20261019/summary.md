# R97 GIF 区间事件状态辅助监督

日期：2026-10-19。实验使用 R92 的 PHD2/GIF 公共片段和冻结 RGB ResNet18 特征，不使用官方测试信息。

## 设计

从公开 `train.json` 选择区间构造 8 点状态：区间前、选择区间内、区间后。没有选择区间的样本不计算状态损失，也不被写成硬负。比较相同 RGB TCN/输出头的两个版本：状态损失权重 0 和预注册的 0.3；源级 split、85% 固定集合解码和优化器相同。

## 结果

| 模型 | 参数 | dev macro F |
|---|---:|---:|
| 无状态控制 | 203,268 | 0.416244 |
| 状态辅助权重 0.3 | 203,268 | 0.415464 |

448 个源的配对差为 **−0.000780**，95% CI **[−0.003117,+0.001542]**。状态监督未通过增量门，且点估计退步。

## 判定

关闭“PHD/GIF 区间前/中/后辅助状态头”这一具体配方，不制作官方包。这个负结果只说明当前 8 点片段、区间投影和 RGB 表征下，辅助状态与最终固定预算选择目标不一致；它不否定完整事件上下文或更可靠的联合人工监督。下一步若继续上下文路线，应改用完整事件/音频可观测监督或直接集合效用目标，并预先固定可识别的源级留出门。
