# DINOv3 匹配对照与标签修复：2026-10-20

本报告修订 v1 原型的路线结论。v1 数据仍保留，但未使用 R70 的训练集特征归一化、且 head 不同，不能据此比较编码器；v1 的 soft 标签存在同用户重复计票错误，union/soft 比较失效。改变 seed 时也改变了源划分，不能称为固定划分上的三次初始化复现。

## 后续路线的必要性

1. **必须先完成：修复后的时间监督合同对照。** 固定源划分和初始化，union/soft共用BCE或共用MSE，报告位置控制和源级配对差；不能继承旧soft比较。只有检验可泛化内容增量后再扩大时间训练。
2. **空间主判别：连续区域池化 × 更高分辨率。** 当前129窗口被量化到约16种区域；先在缓存上用patch与窗口交叠面积作连续池化，再以相同头对照224/448观察。两项分别隔离区域量化和原始细节缺失。只是一条待验证机制；若仍显著落后V9，不继续同配方扩大训练。
3. **必要备选：AViMoS native-crop适配。** R105有增量但小、且blend过拟合；应用真实crop标签适配头、使用训练内选模，独立于DINO更换路线。没有证据支持再用saliency centroid直接替代构图点，亦不重启音频。
