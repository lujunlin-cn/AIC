# DINOv3 计划消融重评估（2026-10-20）

## 结论先行

DINOv3 仍值得验证，但首版计划中的 T-0/T-1/S-0 需要改成“一个主变量 + 能区分解释的负控制”。已有结果已经回答了不少结构问题：PHD/GIF 弱监督下的浅层 TCN 可以作为控制，区间前/中/后辅助监督、多视图标量融合、邻帧交互和无目标域的摘要迁移都没有形成可靠官方路线。新的实验价值只在于回答 **DINOv3 的视觉表示是否有新增信息**，不能再把时序头、损失、预算和空间合同一起改动。

当前没有证据可以把公开代理增量换算成官方分数。因此下面的“预期效果”都是晋级条件和条件性范围，不是官方涨分承诺。

## 已有实验已经覆盖的变量

| 计划变量 | 已有证据 | 对新实验的处理 |
|---|---|---|
| RGB + 浅层 TCN 是否能学习 PHD/GIF 弱标签 | R92 RGB 固定 85% 集合 F=`0.415595`；R97 同类 RGB 控制=`0.416244` | 直接复用 R92/R97 的控制合同；不把 TCN 本身称为 DINOv3 新贡献 |
| 低频/高频/运动视图是否提供时间增量 | R92 多视图=`0.415335`，相对 RGB `−0.000260`，运动时间置换未下降 | 不再做传统多视图或标量 bank；DINOv3 首轮保持纯视觉表示 |
| 区间前/中/后状态辅助是否有用 | R97 相对控制 `−0.000780`，CI 跨 0 | DINOv3 T1 关闭状态辅助损失 |
| TVSum + ResNet18 小模型能否直接迁移官方 | R91 官方=`33.87`，低于 R54=`36.22` | 不使用 TVSum 做主监督；时间训练改用 PHD/GIF 目标域 |
| 邻帧视觉上下文是否改善构图 | R101 `+0.000197`，CI `[-0.001942,+0.002463]`；置换上下文没有变差 | S-0 不加入邻帧交互；patch tokens 先单帧验证 |
| 高 FPS/事件拓扑是否解决时间瓶颈 | R93=`36.32`，R108=`35.62`，R107=`36.43` | F-0 取消；没有原始帧级真值时不把密采样当训练能力 |
| 空间候选效用是否有官方价值 | R70=`36.42`，R70 public native crop 正向；R82=`36.20`，说明 utility→时间重排会失配 | 保留空间路线，但固定时间集合，只做 S-0 |
| DINO 系列是否已被证伪 | V5 DINOv2 H3 在 RV dev gate 失败，但存在域方向、候选和暴露问题 | 不能关闭 DINOv3；必须使用清洁的同候选、同 GT、源级留出对照 |
| 外部时序迁移是否可能有效 | R102 AIKU transfer `+0.003413`，CI `[+0.00080,+0.00610]`，但输入是不可部署的预提取特征 | 作为 T-2 条件实验，不能进入首轮或直接打包 |
| 低层构图/显著性是否有空间信号 | R89 native crop confirm `+0.004104`；R105 AViMoS full head `+0.0035215`，blend holdout 过拟合 | DINOv3 patch S-0 的价值在于更强局部语义和布局表征，不再叠加 saliency blend |

## 改后的时间实验

### T-CONTROL：直接复用历史 RGB 控制

R92 的 RGB cache、source split、8 点/1 FPS 观测、masked weak supervision、TCN 结构、1200 steps 和固定 85% 解码作为匹配控制。若远端 cache 与新环境不能逐项核验，则重新提取 ResNet18 控制和 DINOv3 cache，不能拿 R92 的数字直接当同批对照。

### T-0：DINOv3 CLS 单帧读出（诊断臂）

冻结 DINOv3，只用 `x_norm_clstoken`，经过一个固定输出宽度的投影和单帧读出。投影后的 head 容量与 RGB 控制对齐。这个臂只回答静态语义是否比 ResNet18 更容易读出 PHD/GIF 选择，不作为首选提交包。

### T-1：DINOv3 CLS + 原有 TCN（主时间臂）

只替换视觉表示，TCN、mask、loss、source split、训练步数、keep 和空间父链全部固定。T-1 必须同时跑两个负控制：

1. **position-only**：只用归一化位置和视频长度，检查收益是否只是位置捷径；
2. **within-source temporal permutation**：打乱特征的时间顺序但保持标签和源不变，检查 TCN 是否依赖真实时间对应。

如果 DINOv3 与位置基线差不多，或 permutation 几乎不降，不能把任何代理提升解释成视觉时序能力。

### T-2：AIKU 时序 trunk 转移（条件实验）

只有 T-1 在源级留出上超过匹配控制后才做。保留 R102 的原则：输入投影重新初始化，只转移兼容的时序 trunk；比较 `target-only` 与 `transfer`。这条实验的价值是测试“时序归纳偏置”是否可迁移，不能把 AIKU 1024D 特征直接带到官方推理。

## 改后的空间实验

### S-0-PATCH：DINOv3 patch 主臂

固定 R70 的 129 个合法最大窗口、native crop GT、RetargetVid/LIVE 源级 split、候选 IoU 目标和 head 结构。DINOv3 的候选特征为 `[window_mean, outside_mean, difference, position]`，维度仍为 `3×768+1=2305`，因此与 R70 head 的输入维度和容量可以严格对齐。

必须把候选框先映射到每帧的 DINOv3 预处理坐标，再映射到 patch 网格。letterbox 的 padding patch 要从 inside/outside pooling 的有效像素掩码中排除；不能直接复用 R70 的原始像素到网格公式，否则会把 padding 当内容，空间实验无效。

### S-0-CLS：全局语义负控制

用同一 DINOv3 帧的 CLS 构造候选特征，只保留候选位置几何。若 S-0-PATCH 与 S-0-CLS 都提升，主要解释可能是全局语义或几何先验；若只有 PATCH 提升，才支持局部空间 token 的增量。

### S-0-SHUFFLE：空间因果负控制

在每帧内部随机置换 patch 网格，保持 CLS、候选框、几何和 head 不变。该臂不用于提交，只用于识别空间布局是否真的被使用。S-0-PATCH 的增量在 SHUFFLE 后消失，才支持“patch 布局信息”解释；若不消失，说明 head 主要使用全局统计或位置先验。

### S-1：候选几何和可变宽度（暂缓）

只有 S-0-PATCH 在 RetargetVid 与 LIVE 两个域方向一致、source-macro IoU 增量达到 `+0.005` 且 bootstrap 下界大于 0，才检查 candidate oracle gap，再决定可变宽度或局部框修正。不能在 S-0 失败后用更复杂 decoder 掩盖表示问题。

## 首轮执行顺序和资源分配

1. **smoke**：每个方向 10 个源、单 seed、300 steps，只检查 cache、坐标回映射、有限值和训练收敛；不看最高分。
2. **时间匹配**：先完成 T-CONTROL/T-0/T-1 的同协议单 seed；T-1 只有在 smoke 不出现标签或位置泄漏后才跑 3 seeds。
3. **空间匹配**：S-0-PATCH、S-0-CLS、S-0-SHUFFLE 共用同一 patch cache，先跑 1 seed，再对主臂和 R70 控制跑 3 seeds。RetargetVid/LIVE 必须分开报告。
4. **条件升级**：T-2、S-1、FT-0 都等待主臂通过门槛；不因为 GPU 空闲而提前展开。

## 预期效果与决策门

| 结果 | 解释强度 | 行动 |
|---|---|---|
| T-1 相对 RGB `≥+0.005`，CI 下界>0，position-only 无法解释且 permutation 明显下降 | 有目标域时间表征增量 | 固定空间父链制作一个 DINOv3 时间单变量候选；仍不能承诺官方涨分 |
| T-0 有增量但 T-1 无增量 | 静态语义可见，TCN/弱监督没有利用好 | 不换官方时间头；先停 T-2，研究监督或读出目标 |
| T-1 接近 0 或负，T-0 也接近 0 | DINOv3 视觉表示没有被当前 PHD/GIF 合同读出 | 关闭时间 DINOv3；资源转 S-0/目标监督 |
| S-0-PATCH 两域 `≥+0.005`，CI 下界>0，S-0-CLS/SHUFFLE 不支持位置解释 | 最强的可部署新增证据 | 固定 R54 时间帧集合，只替换空间框，制作一个官方单变量包 |
| S-0 只在 LIVE 或 RV 提升，或 SHUFFLE 也提升 | 域偏差/几何先验/坐标合同问题 | 不打包；先修坐标和来源划分，不做域门控扫描 |
| S-0 公共 IoU 提升但官方回分不升 | 与 R82 类似的代理失配 | 关闭 DINOv3 空间官方迁移，不把 proxy 乘成分数 |

在当前证据下，**S-0 的官方成功希望高于 T-1**：R70 是唯一已经获得官方正回分的空间单变量，而 R107/R93 等时间改动最多持平或小幅波动。DINOv3 不能自动带来 40 分；合理预期是先争取公开源外 `+0.005` 级别的可重复表征增量，再用一个官方单变量包验证是否有约 `0.1` 级别的真实迁移。这个区间只是资源决策参考，不能作为成绩承诺；若源外门不通过，预期官方收益应记为 0。

## 最小风险控制

- DINOv3 权重 `85.7M` 在 9B 上限内，但 frozen backbone、head 和所有辅助推理组件仍计入总参数。
- 不使用官方测试标签、官方回分或由回分反推的样本信息。
- 不把 PHD2 未选中区间写成可靠负例，不把公共 native crop IoU 冒充联合官方 F。
- 首轮不做 ensemble、utility→时间重排、音频、邻帧交互、状态辅助或部分解冻。
