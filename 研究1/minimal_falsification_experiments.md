# AIC 三项最小判别实验：H1 / H2 / H3

协议草案版本：2026-10-19。依据仓库 [`3b28ffc6bf61f0799d91c9ecf6113e83a98223fc`](https://github.com/lujunlin-cn/AIC/commit/3b28ffc6bf61f0799d91c9ecf6113e83a98223fc)。

**执行顺序：先完成合同与基线纠错，再执行 H1。H2/H3 属于条件触发的时间备选，不同时启动多个 backbone。** 本文件提供待实施方案，没有新的目标数据训练结果或官方成绩。

## 1. 实验要回答的三个问题

| 假设 | 可证伪版本 | 单一主要比较 | 不能由它回答的问题 |
|---|---|---|---|
| H1 空间 | 冻结轻量主体信息能在同帧、同候选条件下，提高强空间基线的原生人工 crop IoU | 主体条件候选头 vs 已冻结可复现强空间基线 B0 | 公开 IoU 改善能增加多少官方分 |
| H2 结构 | shot 条件位置与局部新颖性，在静态语义控制之外提高固定预算的观察选片覆盖 | 静态语义+结构 vs 相同静态语义控制 | 所有低层结构都比语义更好 |
| H3 运动 | 相机补偿后的局部运动状态，在静态语义控制之外提供稳定时间增量 | 静态语义+已冻结运动状态 vs 相同静态语义控制 | 光流 benchmark 更好是否一定改善 AIC |

H2 若只胜位置、不胜静态语义控制，只能说优于位置。H3 若只在已剪辑多镜头组有效，只能说有域条件的增量。确定性运动补偿改善的是固定容量下的可读信号，不是在信息论意义上创造原视频不存在的信息。

H1 固定 R54 时间输出是空间诊断，不是完整 100M 部署。沿用其具体帧选择时须保留 TimeLens 上游参数；只有替换为 R91 一类轻量时间链、并重新验证后，才能申报对应轻量系统。[E9]

## 3. 指标、源级配对与功效

### 3.1 空间主要指标

对视频源 s、目标比例 r、固定选中且有原生人工标注的帧 t，先平均有效标注者的 IoU，再在该源内平均帧与比例，得到 `Q_s`。主要结果为 `mean_s Q_s`。各比例先等权，避免标注帧多的比例支配源结果。

\[
Q_s=\frac1{|R_s|}\sum_{r\in R_s}\frac1{|T_{sr}|}\sum_{t\in T_{sr}}
\frac1{|A_{srt}|}\sum_a\operatorname{IoU}(B_{srt},G_{srta}).
\]

每个源配对差异为 `d_s=Q_s(new)-Q_s(B0)`。主指标是 source-macro 的平均差异；两个数据域各占一半的 domain-macro 作为单独的次指标，不能混成同一数字。

R70 历史约 +0.07006 是其报告的域均值口径，R89 的 +0.004104 又是另一池与基线。**重算到同一源、同一 GT、同一聚合前，不能用二者的数量级直接评价模型强弱。**[E5][E6]

### 3.2 时间主要指标

有完整逐帧二值 GT 时，在固定 K 下计算该公开任务的时间 F。没有真实空间 GT 时，不添加 IoU，也不叫 AIC 联合 F。

PHD/GIF 为个人选择的正观测与未标注数据。主要指标为固定预算的 **observed selection capture**：

\[
U_{su}(S)=\frac{\sum_{t\in S}w_{su}(t)}{\sum_t w_{su}(t)},\qquad
U_s=\operatorname{mean}_{u\in s}U_{su},\qquad U=\operatorname{mean}_s U_s.
\]

`w_su` 来自该用户已观察到的有效 GIF 选择；默认按实际 PTS 将区间映射到原帧，区间内每个原帧权重为1，同用户重叠区间去重。这是帧覆盖，不是持续时间覆盖；VFR 的按 Δt 时长加权结果只能作另报次指标。每个 `(s,u)` 若分母为0则排除并报告，不能使NaN进入源平均。没有正观测的源不是自动负源。该指标只衡量覆盖已观察选择，不能测未被观察的真实高光召回或空预测性能。[D1]

TVSum 连续重要性可用相同固定预算的归一化重要性总和作摘要代理，但单独报告，不与 GIF 指标混合平均。Spearman 若作为次指标使用平均秩处理 ties。R90 的 16 个开发源不能支持覆盖所有类别的稳定性结论。[E2]

### 3.3 预算与帧列表

已有对应公共回放清单时使用原清单。没有公共 R54 mask 的新视频，在读取标签前固定公共诊断策略：`K=max(1,floor(0.85*N))`，位置基线取中心连续 K 原帧。它是研究控制，**85% 不是当前官方规则，也不是官方 R54 测试视频帧集合**。[O1][E7]

H1 的所有空间政策使用完全相同的帧列表。LIVE 的稀疏框只在这些帧与人工标注交集中计算；全量人工标注帧作为次指标。没有有效交集的源按预注册规则排除并报告，不能记成 IoU=0 或空 GT。

H2/H3 所有组选择相同 K 个原始帧，空间函数对每个原帧的输出事先固定并校验 hash。各组必须使用同一扩展/插值和 tie-breaking，不得有的组按 cell 选择，有的按精确帧选择。

### 3.4 最小实际收益与源数

建议在首个确认集标签开放前固定：

| 实验 | 主指标取值 | 建议最小实际收益 δ | 依据与限制 |
|---|---|---:|---|
| H1 | source-macro 原生 IoU，[0,1] | **0.010** | 要求相对强基线至少 1 个 IoU 百分点，明显高于只对中心的小幅探索信号；不换算官方分 |
| H2 | observed selection capture，[0,1] | **0.005** | 固定高预算下要求 0.5 个百分点的稳定增量；必须核对该数据的真实 headroom |
| H3 | 与 H2 相同 | **0.005** | 与 H2 保持同尺度；补偿额外成本必须由这一级别以上的收益支持 |

这些 δ 是项目的**预注册建议与投入标准**，不是统计学普适常数。先用已暴露开发源估计配对差异标准差 `σ_d`，检查功效和成本，再冻结确认协议。可以在读取新确认标签前修订 δ，但必须解释成本与指标尺度的理由，不能根据确认结果反复调门槛。

按双侧正态近似、80% 功效，未校正的样本量约为：

\[
n\approx (1.96+0.842)^2\sigma_d^2/\delta^2.
\]

例如 δ=0.010、σ_d=0.04 时约 126 个独立源；σ_d=0.08 时约 503 源。δ=0.005、σ_d=0.02/0.04 时相同。它是设计近似，不代替源级 bootstrap，也不把帧数当源数。

本计划有 H1/H2/H3 三个主要假设块。为避免多重尝试放大阳性，最终晋级使用 Bonferroni 的三假设家族 α=0.05：每项报告常规 **95% CI**，并同时报告用于晋级的 **98.333% CI**。H1 另要求同容量无主体消融也被击败；这是同一假设必须同时满足的交集条件，不能以其中任一个显著就晋级，不增加“任选一个阳性”的机会。其他次比较仅探索。

若按该更严格显著性门槛规划，上式的 1.96 改为约 2.394；上述两种方差约需 168、671 源。只完成 H1 时可保留这一保守门槛，不因结果边缘而事后放宽。

上述 80% 功效只针对“真实增量等于 δ 时拒绝零增量”，**不是完整 Go 规则的 80% 晋级概率**。因为 Go 还要求点估计≥δ，真实效果恰为 δ 时，该额外条件通过率约为 50%。实际规划应另外给出 `Δ_alt>δ` 的合理备择情景，用开发源方差模拟完整门槛的操作特性；H1 还要考虑两个必要比较，采用更保守的所需 N。没有这样的信号假设时，只报告上述显著性检验样本量近似。

先用最多 32–40 个已暴露源估计方差和错误类型，再冻结 N。若可用新源最多 200、但估计需要 671，应在执行前声明只能筛掉大失败，不能以宽 CI 的阴性宣称低维机制不存在。不得为了凑功效，把同源片段、标注者、种子当独立样本。

### 3.5 Bootstrap 与随机种子

以 `source_group_id` 为单位配对重采样 10,000 次，seed=20261019。同一源的所有片段、比例、标注者和变体一起抽取。保存每源差异和 bootstrap 配置，报告 percentile CI，并保留小样本偏斜的分布图用于诊断。

确定性 ridge 不需要人为重复随机种子。神经适配器固定 seed=17 为部署候选，主要指标和 bootstrap 只针对这一冻结模型；seed=29/43 仅作训练稳定性诊断，不能查看确认结果后更换部署 seed。报告三者表现及最差 seed，但不把三个 seed 乘进有效源数。若未来采用集成，须在确认前固定分数融合，再解码和评估实际集成输出，并计入所有部署头参数。

### 3.6 Go、No-Go 与证据不足

**Go 必须同时满足：** 配对平均增量 ≥δ；用于家族控制的 98.333% CI 下界 >0；成本和类别条件通过；输入合同与基线谱系无未解决问题。

**可证伪的 No-Go：** 98.333% CI 上界 <δ，表示本配置在当前目标域不支持最小实际收益；若上界 ≤0，进一步支持没有正增量。不能把它扩大为所有模型、所有运动或所有主体特征无效。

**证据不足：** 所有未满足 Go、也未满足效果 No-Go 的情况。例如 CI 同时包含负值与有意义正值；或 δ=.010、估计=.008、CI=[.003,.013]，虽有正信号却未证明达到实际收益门槛。此时不晋级，也不宣称假设被否定。按预先的资源上限停止本轮；若未来补新数据，登记新确认批次，不能在原批次反复窥看后追加直到显著。

**工程 No-Go：** 科学指标通过，但完整模型/成本/许可/复现条件不满足。它否定本次部署选择，不是否定信息通路。

类别需在读结果前固定为：未剪辑固定机位、连续相机移动、已剪辑多镜头，并补充预定的单/多主体及内容类别。对 n≥20 的主要类别，任一类别平均退化超过本项 δ 则不进入广泛部署；n<20 只能列为低功效，不能称该类稳定。该 guard 是实际退化约束，不是对所有类别“没有伤害”的统计证明。

成本默认上限建议为：完整系统 ≤9B，首轮目标 ≤120M；相同硬件、视频和输出条件下，端到端 P50 时间不超过 B0 的 1.5 倍，同时记录 P95 与峰值内存。可在确认前依据 Phase 1 实测调整并冻结。超限只能说明工程代价不合适。

## 4. H1：主体信息是否改善强空间基线

### 4.1 动机与机制

R26、R70 为固定时间集合的空间变化提供了直接证据。R86 同时改点源与 H1 映射，R89 又只证明对中心的小幅开发增量。缺少的是在可复现强控制之上、使用新源原生 GT 的单因素测试。[E5][E6][E8]

### 4.2 一次实验内的政策对照

所有政策使用同一批已冻结帧、目标比例和合法候选族。将每帧 B0 的原始合法框直接加入候选集合，保证不因 snap 到网格而削弱强基线；若原框不合法，先修复基线合同，不能以裁剪修复造成的变化充当特征收益。U²-Netp 只提取一次 mask，不为每组训练新视觉模型。

| 组 | 政策 | 用途 |
|---|---|---|
| C0 | 中心合法窗口 | 测中心偏置与任务难度 |
| C1 | B0：可重跑的当前强空间链 | 主要基线；原始 R70/B3 缓存另作历史回放 |
| C2 | 静态显著主体重心，选择同尺度最近合法候选 | 检验主体位置是否足够 |
| C3 | C2 + 同 shot 内主体跟踪、遮挡/切点重置 | 检验持久性与轨迹是否提高 IoU |
| C4 | 冻结主体特征 + B0 已有特征，低容量候选 IoU 读出 | **唯一主要新候选；C4 vs C1 为主要比较** |
| C4-minus | 与 C4 相同训练源、容量、优化和候选，但全部新增主体输入置零并重新训练 | 排除“只是换了新头”的必要机制消融 |

H1 晋级既要求 C4 相对 C1 达 δ 与置信区间门槛，也要求 C4 相对 C4-minus 的 98.333% CI 下界>0。若只满足前者，可报告新配方的系统增量，不能据此确认主体信息的独立贡献；本轮主体主线不因此晋级。两个条件必须同时满足，不能择优。C4-minus 的输出不是为了取代现役基线，而是隔离新增信息通路。

原 R86 配方与 R88 纠错配方放在已暴露开发集的观测源×映射诊断中：B3点/A1raw点 × 原映射/H1映射。它是解释历史混杂的 2×2 检查，不是四个官方候选。资产不齐则标为无法复现，不用中心回填冒充原配方。

### 4.3 特征与训练

C4 的新增特征限于：前景质量、重心、协方差、熵、候选覆盖、主体边缘截断、主体面积与候选的比例、多人/多峰距离、跟踪有效性。保持 R89 的梯度/对比通路为可选开发控制，并重算完全无运动版本。

U²-Netp 输出的是前景 mask，没有实例 ID。C3 先按训练固定阈值提连通区域，再用重叠、中心距离及已有视觉外观作区域关联；遮挡、合并/分裂或多主体歧义降低可靠性，不能把一个连通域直接当作正确人物身份。轨迹在切点重置，关联失败回退 C2。C4 第一轮只用静态主体量；若开发诊断支持加入轨迹量，须在确认前冻结该唯一版本，并将这些量一并纳入 C4-minus 的置零通路。

训练为候选人工平均 IoU 的 ridge 或 64→32→1 小 MLP；开发阶段二者择一并冻结。只训练一个主要候选头及其同容量消融头，不微调前景网络。按源采样并保留多标注者；不同尺度和数据源不共享错误的 GT 转换。

### 4.4 数据与 oracle

旧 LIVE/RetargetVid 用于开发、坐标回归与方差估计。新确认优先采用合法可用、历史未消费的公开视频原生框；若不存在足够新鲜现成 GT，必须对新公开视频采集原生人工构图标注。下载同一旧源的新编码版本不构成新源。

标注要求：多标注者观看局部视频而非孤立缩略图；按真实目标比例画 crop；不显示模型结果；保存主体选择与不确定性。至少抽样复标检查协议稳定性，不能重复 R42 同账号重复后当双人 GT 的问题。[D2]

候选 oracle 定义为每帧 `max_j mean_a IoU(C_j,G_a)`。只在开发源用 `oracle−B0` 决定候选覆盖是否足够；确认源的 oracle 只能在模型冻结后解释结果，不能回头调候选。若其上界已低于 δ，当前候选族不存在足够空间，应调整候选尺度/观察路径或结束该候选族实验；不能继续搜索读出权重。

这一上界要求所有政策最终框仍来自同一固定候选集。C3/C4 的时间平滑只改变候选评分，最终仍选择集合内框；不得再对坐标做使框离开集合的 EMA。若另研究连续轨迹/插值框，必须重新定义可达输出与 oracle，不能沿用离散候选上界关闭那条路线。Oracle 绝不作为部署选择器。

### 4.5 竞争解释与误差审计

| 解释 | 控制 |
|---|---|
| 只利用中心偏置 | 与按训练源偏移分布校准的几何先验比较；按 GT 偏离中心程度分层 |
| 只是尺度变化 | 第一轮尺度与候选一致；尺度扩展另立实验 |
| 跟踪更平滑而已 | 同时报 IoU 与轨迹变化；IoU 不过门槛就不晋级 |
| 主体热图选择了字幕/灯光 | 盲审错误，单列文字/强光/反射干扰 |
| 只对单人有效 | 多主体、非人主体、出画/遮挡分别汇总 |
| 只对旧数据有效 | 新源确认；已消费池结果只能作探索 |

主体选择错误率需人工判断，不能由与 crop GT 的 IoU 自动推出。预先从新确认源随机抽样最多 32 源、每源 3 个时间点；标注者不知道政策名称。至少两人判断主要事件主体是否被保留，允许“无法确定”，报告分母与一致性。不要只挑最大失败图来估计总体错误率；极端误差另作案例集。

### 4.6 成本、失败与下一步

开发特征可先在 40 源做快速诊断；确认 N 按第 3 节功效确定。冻结 U²-Netp 可在单 GPU 推理，小头可在 CPU 训练；确切吞吐先测 1,000 帧。原生标注与资产恢复可能比训练更耗时，必须单列。

若 C4 胜 B0 且通过同容量消融及全部门槛，进入空间模块集成。跟踪是否进入 C4 必须在开发阶段冻结；C3 vs C2 仅作探索诊断，不单独使用确认结果晋级另一个跟踪模型。若有高 oracle 但所有头失败，定位主体信息/读出问题；若 oracle 低，优先候选覆盖；若充足功效下增量低于 δ，停止本轮空间小模型路线，触发 H2/H3 备选。

## 5. H2：shot 条件结构是否超出位置与静态语义

### 5.1 特征定义与组别

固定 ResNet18、解码网格、空间输出和 K。基础位置包含全片相对时间、距首尾距离和视频长度的训练期标准化值。结构特征限于 shot 相对位置、shot 时长、距最近切点时间、邻域归一化 embedding 新颖性及局部重复率。

| 组 | 输入 | 比较目的 |
|---|---|---|
| T0 | 位置策略/位置读出 | 强位置控制 |
| T1 | T0 + shot 长度、相对位置、边界距离 | 镜头结构贡献 |
| T2 | T0 + shot 内局部新颖性 | 新内容或状态变化 |
| T3 | T0 + 完整低维结构组 | 手工路线的最佳预注册组合 |
| T4 | T0 + 冻结 ResNet18 静态特征 | 同源轻量语义控制 |
| T5 | T4 + T3 的新增结构 | **主要比较 T5 vs T4** |

这些是复用同一特征缓存的低容量读出，不是六个并行训练 backbone。结构组的所有规范化只由训练源拟合。R90 的错误差分不得直接复用。[E2]

### 5.2 数据与任务偏移

主要采用 source-disjoint 的 PHD/GIF 个人选择标签；旧已消费 PHD 子池只能开发，从未进入本项目选择的原视频作为候选确认来源。重新取得源视频时核对剪辑版、时长和 GIF 端点，不能仅靠同一 YouTube ID 假定完全对齐。[D1]

TVSum 只用于语义控制和摘要代理诊断。新确认优先覆盖固定机位、相机移动和已剪辑三类。若没有完整二值时间标签，主指标使用 observed selection capture，按第 3 节定义。不能把 soft importance 的 AP 当通用高光 AP。

### 5.3 竞争解释

| 解释 | 预注册检查 |
|---|---|
| 结构只是位置代理 | T5 vs T4；训练源残差化；在相同相对位置 bin 内报告差异 |
| 只是视频长短 | 长度分层；长度分布匹配后配对差异 |
| 只是类别/剪辑风格 | 预定类别与来源分层；train-only 类别先验读出作诊断 |
| 切点错误改变峰值 | 开发源盲审固定数量边界；报告软转场/闪光错误；确认不按模型收益改切点 |
| 新颖性仅来自切换 | shot 内计算；切点邻域屏蔽控制 |
| 模型只记来源 | 同拍摄事件/上传者重复合组；跨来源开发与独立确认 |

只有 T3 相对 T4 不劣于预注册 δ、类别表现更稳定且成本更低，才有理由讨论“低维结构比当前高维静态语义更稳健”。单看 T3 胜 T0 不足以支持这一表述。稳健性比较需报告各源方差与类别，不仅报告均值。

### 5.4 成本、失败与下一步

复用冻结 ResNet18 缓存；PySceneDetect 与核相似度计算先在 CPU。全长自相似矩阵为 O(N²)，只在预注册的分块/低频网格计算，不用一次性全原帧核矩阵。初轮没有 TransNetV2 微调。

T5 未达门槛且功效足够，则停止相同结构 bank 的复杂头升级。若主失败来自可证实的 shot 识别错误，可启动一次冻结 TransNetV2 对照，作为新假设与新确认批次，不在同一确认集反复调检测阈值。

T5 达门槛后，才允许路线 B 的小 TCN；须额外击败同容量静态 MLP，以确认顺序和时窗贡献，而非仅增加参数。

## 6. H3：相机补偿残差与动作阶段

### 6.1 固定提取合同

优先 DIS 在固定缩放尺寸上估计稠密流，用 LK/RANSAC 拟合背景仿射模型；前景 mask 只用于排除/分组，不在每组更换模型。单应模型只在开发源验证匹配覆盖和可靠性后固定启用。

全局位移 `u_cam(p)=project(Hp)−p`，残差 `r(p)=u(p)−u_cam(p)`。低分辨率流先按 resize/letterbox 逆变换回原 coded 坐标：若 x/y 缩放分别为 s_x/s_y，则位移为 `(u_x/s_x,u_y/s_y)`；再除以原图对角线和真实 Δt。全局矩阵与 mask 也使用一致坐标变换，不能以缩小图像像素位移直接除原图尺度。前景、背景缺失分别 mask。

### 6.2 组别与主要比较

| 组 | 输入 | 用途 |
|---|---|---|
| M0 | 位置基线 | 最低控制 |
| M1 | M0 + 原始流稳健统计 | 原始运动是否可用 |
| M2 | M0 + 全局相机运动参数 | 相机/拍摄方式能解释多少 |
| M3 | M0 + 残差流统计与可靠性 | 补偿后的局部动作 |
| M4 | M3 + 前后窗能量、onset/offset、峰后停留 | 可观察运动阶段 |
| M5 | 与 H2 相同静态语义控制 T4 | 必须击败的语义控制 |
| M6 | M5 + 开发阶段已冻结的 M3 或 M4 新增量 | **主要比较 M6 vs M5** |

M3 vs M1 是机制次比较；M4 vs M3 区分时序阶段。开发时在 M3/M4 中只选一个进入主要确认。不为每个阶段训练独立大模型。

原始与残差统计保持相同维度和聚合函数：中位/90%速度、运动面积、方向熵、局部对比、前后向一致性。M2 的参数包括平移、旋转/尺度及可靠性，单列其自身预测能力，防止把拍摄方式误当主体动作。

### 6.3 采样、切点与阶段控制

主采样固定 4 FPS。开发阶段在预先抽取的同一批 12 源上做一次 1/4/8 FPS 稳健性诊断：来自同一时间轴，保持输出 K；比较流有效比例、特征分布和最终排名一致性。诊断后固定确认频率，不在确认集择优报 FPS。

切点邻域不作为正常速度/加速度；保留 cut indicator，单报排除切点后的结果。低运动“结果反应”需要前后视频上下文，不能仅由曲线低谷赋语义标签。

匹配数少、背景覆盖差或重投影误差高的窗标为补偿失败。主比较不能只剔除对候选不利的视频：失败窗保留缺失指示，按预注册 fallback 返回位置/静态控制。

Fallback 在全视频统一选择 K 之前执行。优先用 `score=baseline_score+motion_residual`，失败窗残差设为0；不能将两个独立模型的未校准分数直接混用。若确需独立头，在开发期冻结分数尺度校准，然后只执行一次全视频精确 K 解码，禁止各窗选帧后合并改变预算。

### 6.4 如何判断阴性结果的来源

| 观察 | 解释与动作 |
|---|---|
| M2 很强，M3 无增量 | 可能是相机/剪辑风格代理；不称前景动作收益 |
| M1 只在切点附近强 | 转场混杂；排除后仍需成立 |
| M3 开发强、确认弱 | 重现源外过拟合；停止扩大 bank/头部 |
| M3 只在少量运动密集视频强 | 报告条件域；不整体部署，除非预注册可靠域门控也经独立验证 |
| M3 阴性且流/补偿可靠性低 | 先做固定 RAFT-small 质量控制，不能直接否定运动信息 |
| M3 阴性且控制流可靠、功效充分 | 反对当前运动统计的实际增量；转监督/其他输入 |
| M4 超过 M3 | 支持局部阶段有用；仍不证明理解了得分、成功或反应语义 |

RAFT-small 仅在可证实的传统流错误构成瓶颈时开启。固定小子集、同像素/时间输入，对比流质量与高光增量；准确流仍可能与高光无关。其额外参数和部署算子按登记表计入，不能将该控制变成光流排行榜搜索。[M1]

### 6.5 成本与失败分支

DIS/LK 可在 CPU 运行，成本主要由解码、像素数和采样频率决定；无学习参数不等于免费。200×120秒样例在 4 FPS 约 96,000 个采样点，64D float32 统计约 24.576 MB，而完整 320×180 流约 44.237 GB，应默认只保存统计和抽样可视化。

M6 达门槛才进入轻量时序适配。若正确实现、足够可靠流、充分功效下仍不支持 δ，停止“光流大小/差分拼接”方向，不立刻替换成更大的视频 backbone。

## 7. 统一排除竞争解释

| 竞争解释 | 必须保持不变或单独审计的项目 |
|---|---|
| 只是位置代理 | 全片位置、shot 位置、长度分别记录；匹配位置 bin 与静态控制 |
| 运动只是切点代理 | cut mask、软转场、闪光单列；shot 内对比 |
| 显著性只是中心偏置 | 中心几何先验、偏心主体组、同尺度候选 |
| 表征只是类别识别 | 类别先验控制、类内源配对、来源隔离 |
| 收益来自预算 | 逐视频 K hash 完全一致；先不研究空预测 |
| 时间收益来自框变化 | 原帧→框映射 hash 完全一致 |
| 空间收益来自选帧变化 | 原帧列表 hash 完全一致 |
| 预训练或历史暴露泄漏 | 预训练来源和 source group 审计；未知明确登记；新确认源 |
| 平滑降低可见抖动但损伤指标 | IoU 为主要指标，轨迹变差只作描述 |
| 只增加模型容量 | 相同低容量头/等容量静态对照；新增特征分别消融 |

这些控制能够缩小解释范围，不能将观察性视频数据变成对所有机制的随机因果实验。报告使用“支持增量”“与解释一致”等限定措辞。

## 8. 可交给实现者的模块与函数接口

以下包和命令是**待实现的设计**，当前仓库没有这些新模块。首先按固定 commit 创建隔离研究分支，不覆盖现役包。

| 新模块 | 核心接口 | 输出/防错要求 |
|---|---|---|
| `research_aic.audit` | `audit_manifest(manifest, protocol) -> AuditReport` | GT来源、占位、重复、曝光、时间轴、权重谱系；错误不得静默回填 |
| `research_aic.timeline` | `decode_index(path) -> list[FrameRecord]` | 原帧号、PTS、coded尺寸、旋转、文件SHA |
| `research_aic.features.spatial` | `extract_spatial(rgb, models, transform) -> Features` | mask/主体/几何；无运动分支不得读前帧 |
| `research_aic.features.motion` | `extract_motion(frames, pts, masks, shot_ids) -> FeatureBank` | raw/global/residual/stage及valid；每窗端点可追踪 |
| `research_aic.features.structure` | `extract_structure(embeddings, pts, shots) -> FeatureBank` | 一致归一化与真实Δt；不读取标签 |
| `research_aic.probe` | `fit_probe(train_bank, labels, config) -> FrozenProbe` | 保存系数、均值/方差、训练源SHA；推理不能 refit |
| `research_aic.decode` | `select_exact_k(scores, frame_ids, k, tie_policy)` | 恰好K、原帧严格排序、不重复；函数不接收GT |
| `research_aic.evaluate` | `paired_source_metrics(pred_a, pred_b, public_gt, protocol)` | 源级明细、有效分母、95%/98.333%CI、分层、成本 |
| `research_aic.package` | `build_candidate(index, frozen_graph, output_dir)` | 无标签入口；完整参数/权重/处理器清单；不上传 |

建议的单次流水线命令如下，须先实现模块与配置后才能运行：

```bash
python -m research_aic.audit --protocol configs/research_h1_v1.yaml --fail-on-placeholder
python -m research_aic.extract --protocol configs/research_h1_v1.yaml --split train,dev
python -m research_aic.probe --protocol configs/research_h1_v1.yaml --freeze-selected-candidate
python -m research_aic.evaluate --protocol configs/research_h1_v1.yaml --split confirm --locked-only
python -m research_aic.report --protocol configs/research_h1_v1.yaml
```

训练入口必须拒绝 `official_hidden_test` 来源和未登记的 label 来源；确认入口只接受锁定权重与协议 hash。该设计实现用户既定数据边界，不增加新的官方提交动作。
