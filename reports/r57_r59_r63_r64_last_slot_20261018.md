# R57/R59 official postmortem and R63/R64 last-slot decision (2026-10-18)

## Facts

- R54 TimeLens2 centre residual + V9: **36.22**.
- R57 fixed +2 s late window + V9: **34.76** (-1.46 vs R54; -1.28 vs R26=36.04).
- R59 4 fps interval-inside/endpoint residual + V9: **35.04** (-1.18 vs R54; -1.00 vs R26).
- These scores are user-reported and should remain bound to the exact uploaded artifact when platform SHA is available.

## Why the public proxy failed to predict R57

The 18-view proxy selected a small, source-biased set. It did not represent the 426-video test domain, and its +2 s rule changes the full frame mask by roughly 14k swaps and a normalized location shift of about +0.071 from R26. The official score shows that a global late translation moves many videos away from their useful frames. R54's smaller +0.0197 displacement was therefore not evidence for a universal late shift; it was at most a video-conditional correction.

## Why R59 failed

The 4 fps endpoint/membership score changes 14,028 frames relative to the V9 centre parent (424/426 videos). It treats predicted interval boundaries as high-value observations, but endpoint uncertainty and the 85% budget make a boundary bonus expensive: frames are removed from the centre set even when the interval is broad, wrong, or does not correspond to the native high-light frame. The dense run increases observation density but does not solve temporal value calibration. The result rejects this uncalibrated dense endpoint decoder for direct submission; it does not prove that dense observation cannot help a learned/calibrated decoder.

## R63/R64 last slot

R63 utility:
`rank(center)+0.20 rank(interval)+1.0 rank(V9-R26 geometry disagreement)`.
It changes 12,572 frames, 425 videos, has 36 non-contiguous videos, and mean normalized position 0.56669. This is close to the late position that R57 disproved. Its only positive argument is a new, explicit hypothesis: V9/R26 crop movement could mark state or composition transitions. This remains unverified and uses the same V9/R26 disagreement both as temporal acquisition signal and as a space co-intervention.

R64 reverses the term:
`rank(center)+0.20 rank(interval)-1.0 rank(disagreement)`.
It changes 22,741 frames, all 426 videos, has 107 non-contiguous videos, and mean normalized position 0.44301. It has no supporting score or independent positive proxy. It selects stable spatial frames, but stability can mean static background or crop-head bias. Its pairwise interpretation would be valuable only if R63 and R64 were both uploaded; one slot cannot identify the sign.

**This original decision is superseded.** Both packages used stable ordinal ranks for the geometry term. Since most geometry deltas are tied, that implementation injects frame-index position bias; neither package is a valid test of its stated mechanism. Do not upload R63 or R64. If the remaining slot is intentionally reserved for a high-risk mechanism test, use the corrected R67 package below. If preserving expected score is the objective, submit R54 or R26 instead.

## Interpretation boundary

R57/R59 do not show that TimeLens2 itself is useless: R54 remains positive, and both failures change the frame mask far more aggressively than R54. They show that uncalibrated global shift and endpoint over-selection are wrong. The next research direction should be a **small, conditional residual** gated by event confidence/interval length and spatial reliability, with exact centre mask retained for low-confidence videos. A future joint utility must be validated by source-held-out labels before using an official slot.

## Corrected candidate

The current R63/R64 builders use stable ordinal ranks. Because most geometry displacements are tied or numerically near zero, this gives equal values different frame-index ranks. A corrected rebuild is `R67_JOINT_V9_DISAGREEMENT_TIEAVG_G1`: center and interval use the exact R54 stable rank, while only geometry disagreement uses tie-aware average rank (with the R53 geometric-noise threshold). The gamma-zero output reproduces R54 on all 426 frame sets and serialized predictions. At gamma=1 it changes 2,427 frames versus R54 and has mean normalized position 0.51977. The package has 426 videos, 199,037 predictions, 8.854531425B declared parameters, and passes both local validators. Prediction SHA is `4655d73b5e8a93398b75c1ff2c6ae8d6110e061750d0350db23283d6d4490beb`; ZIP SHA is `550bf1c87d2fa03f046b6dfd581882bce6d47850585789ed7e09a175ec2d34bd` (old tieavg package archived). This corrected candidate is the only defensible high-risk submission in this family; current R63/R64 should be treated as invalid mechanism tests.
